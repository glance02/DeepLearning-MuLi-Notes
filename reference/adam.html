Adam：公式与代码对照

手敲用的直接实现：显式计算两份偏差校正后的历史统计量。

符号与变量

符号代码含义
θparams[key]当前参数数组；可以是 W1、b1、W2、b2
gₜgrads[key]第 t 次更新时，损失对该参数的梯度
mₜself.m[key]梯度的指数加权平均，保留正负方向
vₜself.v[key]梯度平方的指数加权平均
tself.step更新次数；与训练代码中表示标签的 t 无关
α、β₁、β₂、εlr、beta1、beta2、eps学习率、两份历史的保留比例和分母的小常数

m、v 与各自参数同形。数组乘法、平方、平方根和除法均逐元素执行，g² 不是矩阵乘法。Adam 的 v 不是 Momentum 里表示更新速度的 v。

一次更新的公式

初始化 m₀=0、v₀=0；每次调用 update 先让 t 增加 1。

mₜ = β₁mₜ₋₁ + (1−β₁)gₜ
vₜ = β₂vₜ₋₁ + (1−β₂)gₜ²
m̂ₜ = mₜ / (1−β₁ᵗ)，v̂ₜ = vₜ / (1−β₂ᵗ)
θₜ = θₜ₋₁ − α m̂ₜ / (√v̂ₜ + ε)

β=0.9 表示旧平均占0.9，新观测占0.1；不是取最近九次的简单平均。零初始化会使早期的历史估计偏小，校正因子用于抵消这种初始化影响。这里的“偏差”与网络偏置 b 是两个概念。

公式与参数默认值依据Adam 原论文 Algorithm 1，第2页；偏差校正见第3节。本文代码按公式直接编写，不依赖教材作者的源码。

Adam实现

import numpy as np


class Adam:
    def __init__(self, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.step = 0
        self.m = None
        self.v = None

    def update(self, params, grads):
        # 只在第一次调用时初始化历史状态
        if self.m is None:
            self.m = {}
            self.v = {}
            for key, val in params.items():
                self.m[key] = np.zeros_like(val)
                self.v[key] = np.zeros_like(val)

        # 一次 update 加一次，放在参数循环外
        self.step += 1

        for key in params:
            g = grads[key]

            self.m[key] = self.beta1 * self.m[key] + (1 - self.beta1) * g
            self.v[key] = self.beta2 * self.v[key] + (1 - self.beta2) * g ** 2

            m_hat = self.m[key] / (1 - self.beta1 ** self.step)
            v_hat = self.v[key] / (1 - self.beta2 ** self.step)

            params[key] -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

if 内只初始化；step 加一及最后的 for 每次执行。m_hat、v_hat 是本轮校正结果，原始 m、v 留待下一轮继续累积。Python 的 ** 表示乘方，例如 beta1 ** self.step 对应 β₁ᵗ。

# 放在训练循环外，保留同一个优化器的历史状态
optimizer = Adam(lr=0.001)

# 放在训练循环内，替换原来的手动 SGD 更新
grads = network.gradient(x_batch, t_batch)
optimizer.update(network.params, grads)

参数数组沿用网络中的浮点数组；update 原地修改它们，无需 return。梯度由 network.gradient 计算；Adam 不负责反向传播，也不修改输入图片。
