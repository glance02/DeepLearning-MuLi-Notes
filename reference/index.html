线性可分性与XOR

单个感知机的边界 w₁x₁+w₂x₂+b=0 是一条直线。XOR的同类点分布在正方形的对角，单条直线无法把两类同时分开。

def XOR(x1, x2):
    s1 = NAND(x1, x2)
    s2 = OR(x1, x2)
    return AND(s1, s2)

组合多层先产生中间表示，再判断输出。表达能力不足不能靠反复试单层参数解决。按本书约定，层数只统计有权重的层，输入层不计入。

05 误差反向传播法

书内121—161页

计算图与链式法则

∂L/∂x = (∂L/∂out) · (∂out/∂x)

前向计算数值，反向传回最终损失对各变量的导数。dout是传入的∂L/∂out，乘上本节点的局部导数，才得到∂L/∂x。

若out=x×y、L=5×out，那么dout=5；x=3、y=4时，dx=20、dy=15。

dx = dout * local_derivative
# 损失对自身的导数为1：∂L/∂L = 1
dout = last_layer.backward(1)

教材5.1—5.2 · 链式法则完整笔记

加法层与乘法层

前向反向
out=x+ydx=dout，dy=dout
out=x×ydx=dout×y，dy=dout×x

乘法层前向保存x、y，反向交叉相乘。若一个变量流向多条分支，回到该变量的导数要相加。

def backward(self, dout):
    dx = dout * self.y
    dy = dout * self.x
    return dx, dy

乘法层逐步解释数值短练习教材5.3—5.4

ReLU层

输入x≤0时，前向输出0，反向也传0；x>0时，前向保留原值，反向原样通过。教材在x=0处采用导数0。

mask保存的是本轮前向输入的位置判断，反向不重新判断dout的正负。

# forward中保存
self.mask = (x <= 0)
# backward中复用
dx = dout.copy()
dx[self.mask] = 0

教材5.5 · 激活层自己的Relu

Sigmoid层

dx = dout · y(1 − y)

令y=sigmoid(x)，局部导数为y(1−y)，所以反向直接复用前向的输出y。

y=0.9、dout=2时，dx=2×0.9×0.1=0.18。y靠近0或1时，局部导数很小，连接第六章的饱和问题。

def backward(self, dout):
    return dout * self.out * (1.0 - self.out)

教材5.5 · Sigmoid与梯度消失的联系

Affine层与矩阵梯度

Y = XW + b

前向Y=XW+b。X为(N,D)，W为(D,H)，dout为(N,H)，所以dx回到(N,D)，dW回到(D,H)。

转置来自矩阵乘法的求导关系；先逐元素理解，再用形状检查结果。

dx = np.dot(dout, self.W.T)
dW = np.dot(self.x.T, dout)
# self.x是当前前向缓存的X

逐元素推导与形状Affine短课教材5.6.1

批量Affine与偏置梯度

形状(H,)的偏置加到每个样本。反向时，这N条分支对同一个b的贡献要相加，沿样本轴求和。

若两行dout分别为[1,2,3]和[4,5,6]，则db=[5,7,9]。损失层已包含平均因子时，这里不再除N。

db = np.sum(dout, axis=0)
# dout: (N, H)
# db:   (H,)

批量与共享偏置自己的Affine

Softmax-with-Loss层

∂L/∂scores = (y − t) / N

softmax把得分变成概率，交叉熵比较概率与正确标签。合在一起反向时，公式简化为(y−t)/N。

这里t是one-hot标签，N是样本数，dout=1。除以样本数对应本章平均损失。

batch_size = self.t.shape[0]
dx = (self.y - self.t) / batch_size

教材5.6.3 · 损失层自己的损失层

网络组装与梯度计算

按Affine1→ReLU→Affine2连接，最后接损失层。gradient先做本轮前向以保存缓存，再从损失层倒着传播，收集各Affine的dW、db。

grads与params同名、同形；计算梯度后，还要由优化器更新参数。

Momentum参数更新

v保存历史更新步长。先把旧v衰减，再加入当前负梯度，最后把v加到参数上。

v和每个参数同形，首次调用时初始化为0。最后一行必须实际赋值；单写params[key]+v不会改变参数。

v = momentum * v - lr * grad
param += v

教材6.1 · Momentum自己的实现

AdaGrad参数更新

h累计每个参数历次梯度的平方。更新时除以√h，使不同参数获得不同的有效步长。

h只初始化一次；不能每次update都清空。分母中的微小值用于避免除零。

h += grad * grad
param -= lr * grad / (np.sqrt(h) + 1e-7)

教材6.1 · AdaGrad自己的实现

Adam参数更新与偏差校正

m保存梯度的指数加权历史，v保存梯度平方的指数加权历史。两者从0开始，按更新次数做偏差校正。

本阶段以会使用为目标，需要公式或初始化层级时再回查完整实现。

m_hat = m / (1 - beta1 ** step)
v_hat = v / (1 - beta2 ** step)
param -= lr * m_hat / (np.sqrt(v_hat) + eps)
