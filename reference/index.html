感知机：先求和，再作阈值判断

a = w₁x₁ + w₂x₂ + b式（2.2）

a > 0 输出1，否则输出0。与阈值形式的关系是 b = −θ。

a = np.sum(w * x) + b
return 1 if a > 0 else 0

权重决定输入的贡献，偏置调节激活的容易程度。固定权重时，偏置越大越容易输出1。

教材 2.2—2.3 · 书内27页Markdown笔记自己的代码

为什么一层做不了XOR

单个感知机的边界 w₁x₁+w₂x₂+b=0 是一条直线。XOR的同类点分布在正方形的对角，单条直线无法把两类同时分开。

def XOR(x1, x2):
    s1 = NAND(x1, x2)
    s2 = OR(x1, x2)
    return AND(s1, s2)

组合多层先产生中间表示，再判断输出。表达能力不足不能靠反复试单层参数解决。按本书约定，层数只统计有权重的层，输入层不计入。

激活函数与非线性

函数表达式要点
阶跃x>0时为1，否则0在0处跳变
sigmoid1 / (1 + e−x)平滑；sigmoid(0)=0.5
ReLUmax(0,x)负值置0；正值保留

隐藏层的非线性让多层结构有新的表达能力；连续的线性变换加偏置仍可合并为一层。输出层按任务选函数，回归可用恒等函数。

隐藏层sigmoid值不自动等于某类别概率；要结合输出的定义理解。

前向传播：形状先行

A₁ = XW₁ + b₁， Z₁ = sigmoid(A₁)式（3.9）
# N个样本，每个D维，隐藏层H个神经元
x.shape  # (N, D)
W1.shape # (D, H)
b1.shape # (H,)
a1 = np.dot(x, W1) + b1  # (N, H)
z1 = sigmoid(a1)         # (N, H)

W₁每列对应一个隐藏神经元，每行对应一个输入分量。矩阵乘法先检查内侧维度是否一致。激活函数逐元素作用，保持形状。

softmax：分数 → 概率

yk = eaₖΣᵢ eaᵢ式（3.10）
c = np.max(a, axis=-1, keepdims=True)
e = np.exp(a - c)
y = e / np.sum(e, axis=-1, keepdims=True)

同一样本的所有分数减去同一常数，结果不变；减最大值可避免指数溢出。每个样本各类别概率之和为1。

(N,C) 输入应按类别轴归一化，检查 y.sum(axis=1)。你第3章的一维实现不直接适用于二维批概率；公共工具文件已支持批处理。

两种损失：平方误差与交叉熵

E = ½ Σₖ (yₖ − tₖ)²式（4.1）

按书中名称称“均方误差”，但此处实现是平方误差和的一半，没有除以类别数。

E = −Σₖ tₖ ln yₖ = −ln y正确类式（4.2），one-hot标签

正确类概率0.6时，损失约0.511；概率0.1时，约2.303。正确类概率越大，惩罚越小。

实际代码加 1e-7 避免log(0)。softmax负责提供概率，交叉熵结合正确标签进行评价。

教材 4.2.1—4.2.2 · 书内85页Markdown笔记自己的代码

平均交叉熵与配对索引

E = −1N Σₙ Σₖ tₙₖ ln yₙₖ式（4.3）
# 两个样本，真实类别分别是2、0
y = np.array([[.1, .2, .7], [.8, .1, .1]])
t = np.array([2, 0])
p = y[np.arange(2), t] # [y[0,2], y[1,0]] → [.7, .8]
loss = -np.mean(np.log(p + 1e-7)) # 约0.290

除以的是样本数N，不是类别数。one-hot标签可先按行argmax转成类别编号；单样本先整理为一行，统一按批处理。

accuracy：统计正确比例

accuracy = 预测正确的样本数总样本数
p = np.argmax(y, axis=1)
t = np.argmax(t, axis=1) # 这里假设t是二维one-hot
accuracy = np.sum(p == t) / x.shape[0]

准确率通常分段不变，参数微小变化时未必变；损失能更细地反映预测概率的变化，因此训练用损失指导更新。

数值微分：函数规则与求导位置

f′(x) ≈ f(x+h) − f(x−h)2h
numerical_gradient(f, x)
# f：函数的计算规则
# x：在哪个位置求梯度，不是代替函数

f = lambda v: v[0]**2 + v[1]**2
# 在[3,4]处，梯度约为[6,8]

求一个分量的偏导数时，固定其他分量。h不能盲目取到极小；教材示例使用10⁻⁴。

例如求第二个分量的偏导数，比较 f([3,4+h]) 与 f([3,4-h])，第一个分量保持3。

梯度与梯度下降

Wnew = W − η ∇WL式（4.7）

正梯度指向局部上升最快的方向；下降时减去梯度。梯度形状与参数一致，每个元素对应一个参数的偏导数。

grad = 0.2
lr = 0.1
# Δw = -lr * grad = -0.02，权重减少
# 若grad为负，减去负数会增大权重

方向是局部信息；步长过大仍可能让损失上升，梯度为0也不保证全局最小值。

教材图4-9画的是负梯度；附近文字有把下降方向简称“梯度”的措辞。用定义与更新公式中的减号区分。

教材 4.4—4.4.2 · 书内104页Markdown笔记自己的代码

f(W)为什么不直接用W也能求导

def f(W):
    return net.loss(x, t)

dW = numerical_gradient(f, net.W)

工具函数内部的参数数组与 net.W 是同一个数组。工具函数原地扰动它的元素，net.loss 又通过网络对象读取变化后的权重。

工具函数内部x这里指向net.W，会被临时扰动
net.loss(x,t)里的x输入样本，保持不变
x[idx] = original恢复原权重，再计算下一个偏导数

两个x只是同名，不是同一对象。数值求导完成后权重恢复，得到dW；真正学习更新另行执行。

mini-batch：本轮固定，下轮重抽

ids = np.random.choice(train_size, batch_size)
x_batch = x_train[ids]  # (100,784)
t_batch = t_train[ids]  # (100,10)

grad = network.numerical_gradient(x_batch, t_batch)
for key in ('W1', 'b1', 'W2', 'b2'):
    network.params[key] -= learning_rate * grad[key]

iteration、epoch与打印条件

本章一次iteration是一次参数更新。一个epoch通常指完整遍历训练集一次。60000张图、batch为100，按样本量折算为600次更新。

本书随机有放回采样，600次更新不保证每个样本都被看到；书内116页译注对此有说明。

# i从0开始，第一次更新后就触发
if i % iter_per_epoch == 0:
    ...

# 若想满600次后才触发
if (i + 1) % iter_per_epoch == 0:
    ...

iters_num 控制更新总次数；batch_size 控制每次取多少样本。

数值梯度为什么慢，“高速版”是什么

784→50→10的网络有 39,760个参数。中心差分每个参数计算两次损失，一次更新约79,520次损失计算。

你的本机短测曾外推约43—54秒/更新，10000次约5—6天。这是特定负载下的估算，不是固定耗时；完整训练实验待反向传播实现后补做。

grad = network.numerical_gradient(x_batch, t_batch)
# grad = network.gradient(x_batch, t_batch)  # 第5章实现后替换

当前类没有gradient方法，仅取消注释会报AttributeError。高速版用反向传播算同样键名与形状的梯度，不改变参数更新的基本公式。
