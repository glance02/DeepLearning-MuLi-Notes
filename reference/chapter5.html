5.1–5.2 / COMPUTATIONAL GRAPH

dout 传递的是导数

节点计算局部运算，正向按依赖关系计算数值，反向沿相反方向计算最终损失对各变量的导数。若本层 y=f(x)：

\[\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}\]

dout 是 ∂L/∂y，dx 是 ∂L/∂x。同一变量通过多条路径影响 L 时，把各路径贡献相加。从最终 L 开始的1来自 ∂L/∂L=1。

5.5 / ACTIVATIONS

ReLU 保存掩码，Sigmoid 保存输出

ReLU：x>0 时传回 dout；x≤0 时传0。在0处不可导，教材代码选择0。

self.mask = (x <= 0)  # forward
dout[self.mask] = 0   # backward

Sigmoid：y=1/(1+exp(−x))，局部导数为 y(1−y)。

\[\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}y(1-y)\]
dx = dout * self.out * (1 - self.out)

5.6.1 / AFFINE · EQ. 5.13

转置来自元素级链式法则

\[Y=XW+B,\qquad \frac{\partial L}{\partial X}=\frac{\partial L}{\partial Y}W^{\mathsf T},\qquad \frac{\partial L}{\partial W}=X^{\mathsf T}\frac{\partial L}{\partial Y}\]

单个样本：yⱼ=ΣᵢxᵢWᵢⱼ+bⱼ。输入 xᵢ 影响多个输出，求它的梯度时对输出路径求和；单个 Wᵢⱼ 只直接连接 xᵢ 与 yⱼ。

\[\frac{\partial L}{\partial x_i}=\sum_j\frac{\partial L}{\partial y_j}W_{ij},\qquad \frac{\partial L}{\partial W_{ij}}=x_i\frac{\partial L}{\partial y_j}\]

第一式把每个输入对应的权重转成一列，完成乘积求和；第二式用输入列向量乘输出梯度行向量，形成与 W 同形的矩阵。

NumPy 一维数组 (D,) 的 .T 不改变形状。自己的实现使用二维批输入 (N,D)，单样本也可保留为 (1,D)。

5.6.2 / BATCH AFFINE

广播出去的偏置，反向求和回来

X 为 (N,D)，W 为 (D,H)，输出与 dout 为 (N,H)，B 为 (H,)。

dx = np.dot(dout, self.W.T)       # (N,D)
self.dW = np.dot(self.x.T, dout)  # (D,H)
self.db = np.sum(dout, axis=0)    # (H,)

同一个 W、B 供所有样本使用，因此梯度累计所有样本贡献。例如 dout=[[1,2,3],[4,5,6]]，db=[5,7,9]。dx 返回前一层，dW、db 保存供网络收集。

5.6.3 / SOFTMAX WITH LOSS

得分 → 概率 → 平均损失

教材中 a 为得分，y 为 Softmax 概率，t 为 one-hot 标签。单样本损失 L=−Σₖtₖ log yₖ，组合后的得分梯度为：

\[\frac{\partial L}{\partial a_k}=y_k-t_k\]
# 批量平均损失，反向从 dout=1 开始
dx = (self.y - self.t) / self.t.shape[0]

除以样本数 N，平均因子随导数向前传；Affine 不再额外除以 N。y−t 是 Softmax 与交叉熵组合的结果。

5.7.4 / COMPUTATION

为什么这次只花约20秒

784→50→10 共39,760个参数。数值梯度每次约需79,520次损失计算；反向传播求梯度复用中间结果，只需一次前向和一次反向。

训练循环仍在求出梯度后更新参数，并额外计算更新后损失。你报告本次约20秒完成；耗时依赖机器和运行条件。

换方法后，参数更新公式和训练/测试评价方式仍然适用。
