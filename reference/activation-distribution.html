激活值分布实验：逐行注释

1000个随机样本经过5层前向计算，保存每层输出，再画5幅直方图。

对应自己 Notebook 的代码

采用当前 chapter6.ipynb 的变量名：z 是矩阵乘法结果，a 是 sigmoid 的输出。这里研究初始化时信号怎样传播，没有计算损失或更新权重。

import numpy as np                    # 用 np 调用 NumPy
import matplotlib.pyplot as plt        # 用 plt 调用绘图函数
from common.functions import sigmoid   # 导入自己公共模块中的 sigmoid

x = np.random.randn(1000, 100)          # 1000个样本，每个100个输入特征
node_num = 100                         # 每层100个神经元
hidden_layer_size = 5                   # 向前计算5层
activations = {}                        # 字典：层编号 → 该层输出数组

for i in range(hidden_layer_size):      # i 依次为0、1、2、3、4
    if i != 0:                         # 第一层以外，都使用上一层输出
        x = activations[i - 1]         # 右侧是上一轮保存的整个数组

    w = np.random.randn(node_num, node_num) * 1  # 本层(100,100)权重
    # w = np.random.randn(node_num, node_num) * 0.01
    # 上一行是注释，不执行；改用它可以比较不同的初始化尺度

    z = np.dot(x, w)                    # (1000,100) @ (100,100) → (1000,100)
    a = sigmoid(z)                      # 逐元素经过 sigmoid，形状不变
    activations[i] = a                  # 用当前层编号保存1000×100个输出

for i, a in activations.items():        # 一次取出一个层编号和整层输出
    plt.subplot(1, len(activations), i + 1)  # 1行5列，选中第i+1个子图
    plt.title(str(i + 1) + "-layer")     # 标题为1-layer到5-layer
    plt.hist(a.flatten(), 30, range=(0, 1))  # 展平后按30个区间统计

plt.show()                             # 显示画好的图

数组里的每个维度

数组形状含义
x(1000,100)一行一个样本，一列一个输入特征或上一层神经元输出
w(100,100)一行对应一个输入位置，一列对应当前层一个神经元
z(1000,100)1000个样本在当前层100个神经元上的加权求和结果
a(1000,100)对 z 逐元素应用 sigmoid 后的激活值
a.flatten()(100000,)汇集这一层的全部激活值，用来画一幅分布图

二维数组的 np.dot 在这里做矩阵乘法。对某个样本、某个输出神经元，都是把100个输入分别乘对应权重，再相加。实验没有写偏置项，可视为偏置为零。

核对 NumPy dot 与 本地 sigmoid 实现。

两个循环各在做什么

第一个循环计算网络的5层，每次都会为当前层生成新的 w。它不是训练5次，也不是让输入通过同一份权重5次。

i本轮输入本轮保存
0最初的随机 xactivations[0]
1activations[0]activations[1]
2activations[1]activations[2]
3activations[2]activations[3]
4activations[3]activations[4]

第二个循环只负责画图，i 是字典的键，a 是该层保存的输出数组。它位于第一个循环之外，等5层都算完后执行。

直方图的参数

np.random.randn 从均值0、标准差1的正态分布采样，不是只生成0到1之间的数。权重乘1保持该尺度；乘0.01使其采样分布标准差变为0.01。

sigmoid(z)=1/(1+exp(−z))。理论输出在0和1之间：z=0时输出0.5，负值越大幅度越接近0，正值越大越接近1。由于浮点精度，实际结果可能恰好等于端点。

flatten() 返回一维副本，不改变原数组。hist 的30表示在0到1之间划分30个等宽区间，纵轴为落入各区间的激活值个数；每幅图统计本层100000个输出。range=(0,1) 是 hist 的命名参数，与 for 中的 range(5) 用途不同。subplot 的位置从1开始，因此使用 i+1。

一手说明：randn、flatten、subplot、hist。

输出靠近0或1，为什么会让梯度变小？

当前代码先算 z=xW，再算 a=sigmoid(z)。a 是前向输出；sigmoid 的局部导数为 da/dz=a(1−a)，它描述输入 z 小幅变化时输出 a 的敏感程度。S形曲线两端较平，输出已接近0或1时，输入再小幅改变，输出变化很小。

输出 a局部导数 a(1−a)
0.50.25
0.990.0099
0.010.0099
0.99990.00009999

你在第5章的 Sigmoid.backward 中已写过：

dx = dout * (1.0 - self.out) * self.out

这里 self.out 就是 sigmoid 的输出 a；dout 是后面传来的损失对 a 的梯度。反向传播乘上局部导数，得到损失对本层输入 z 的梯度：

∂L/∂z = (∂L/∂a) × a(1−a)

例如 a=0.99，后面传来 dout=1，则往前传出的梯度是0.0099。若多个 sigmoid 连续处于这种区域，反向经过它们时就会连续乘上小数。

取一个只为说明连乘的标量例子：层间权重均为1，各个 sigmoid 的局部导数约为0.01，后面传来的梯度为1。连续经过三个 sigmoid，梯度约为：

后面传来 1 → 0.01 → 0.0001 → 0.000001 → 更前面的层

实际网络反向传播还包含权重乘法和分支求和。这里展示的是激活函数导数造成缩小的这一部分；如果其他运算没有抵消，多层累积后，靠前层的梯度可能非常小。SGD更新量为 −lr×梯度，于是相关参数几乎不动，学习变慢或停滞。所谓“消失”通常是很小、不足以有效更新，不要求数学上恰好为0。

直方图统计的是前向激活值。它们大量靠近0或1，说明许多 sigmoid 正处在局部导数很小的区域；图本身没有运行反向传播，也没有直接测量梯度。

公式由 sigmoid(z)=1/(1+exp(−z)) 求导得到；实现对应本地sigmoid函数与自己第5章的Sigmoid.backward，衔接教材6.2.2的梯度消失说明。

怎样读当前 Xavier 初始化的5幅直方图

当前 notebook 使用 w=randn(100,100)/sqrt(100)，即将随机权重除以10；采样分布标准差为0.1。这对应教材本实验的 Xavier 初始化。用户提供的图是同一次前向计算的5个层，不是5次训练或5个epoch。

每幅图横轴为该层 sigmoid 输出 a 的数值，范围0到1；纵轴为落入某一区间的激活值数量。每层1000个样本、每样本100个输出，所以一幅图统计100000个值。hist的30将0到1分成30个等宽区间；例如柱高8000表示该区间有8000个激活值，不是8000个样本。各子图纵轴会自动缩放，比较柱子应读刻度。

当前图第1层分布较宽，中间多、两边少；第2层相对收窄，后面几层仍在中间区域保留了一定宽度，没有大量挤在0和1端点，也没有全部压成0.5附近的一根窄柱。各层宽度与形状并非严格单调变化。后面层的局部尖峰不表示梯度突然增大：图里只统计前向输出。

后几层的锯齿可能与随机权重、有限神经元数量以及各神经元输出聚集在不同区间有关。下一层输入是上一层经过sigmoid的输出，已经不同于最初的正态输入，因此后层直方图不需要与第1层保持相同形状。

初始化方式在本节实验中关注的典型现象
randn(...)×1许多激活值靠近0或1，sigmoid处于导数很小的区域
randn(...)×0.01加权输入偏小，输出容易集中在0.5附近，分布很窄
randn(...)/sqrt(输入节点数)当前图中输出主要位于中间，并在深层保留一定分布宽度

sigmoid在a=0.5时局部导数为0.25，在a=0.99时为0.0099。当前图提示大量单元没有处在极端饱和区，因饱和造成的局部导数缩小较轻。但直方图没有直接测量权重梯度、学习速度或准确率，不能仅凭它确认梯度不消失或训练成功。

这里检查的是学习开始前的信号传播状态。解释依据当前实验代码、用户提供的图、sigmoid定义以及本节权重尺度对比；柱子统计语义见Matplotlib hist。

ReLU的三行图：重点比较正值部分的宽度

教材图6-14的三行分别对应标准差0.01、Xavier与He初始化；每行从左到右是同一个5层网络的各层前向输出。横轴是ReLU激活值，纵轴是区间内的激活值数量；它们不是权重分布，也不是训练进度。

ReLU(z) = max(0, z)
输入：[-2.0, -0.4, 0.3, 1.5]
输出：[ 0.0,  0.0, 0.3, 1.5]

负输入被归零，因此三行都会有零附近的高柱。左柱顶到图框时，可见高度不足以读出实际数量。图的横轴只展示0到1，ReLU正值输出可以超过1；这一窗口也不是完整的输出范围。读图时观察剩下的正值部分有没有随层数加深不断向0收缩。

初始化图中变化含义
标准差0.01第1层已集中在0附近，后几层几乎都落在最左侧区间信号尺度很快缩小；并非所有值都恰好等于0
Xavier，标准差√(1/n)正值分布逐层向左收缩，靠近0的值越来越多对本实验的ReLU网络，初始化未能充分保持传播尺度
He，标准差√(2/n)各层正值部分仍保持大致相近的宽度更好地保持了初始化时的信号尺度，零柱仍然正常存在

原教材脚注给出第一行激活值平均数：第1层0.0396、第2层0.00290、第3层0.000197、第4层1.32e-5、第5层9.46e-7。许多后层正数只是非常小，被直方图并进零附近的区间。

He多出的系数2可以这样理解：对近似零中心、正负对称的输入，ReLU把负值归零后，输出的平方平均约只剩一半。He使用2/n的权重方差，在常用独立性等近似下补偿这种缩小；与本实验Xavier相比，标准差乘的是√2，约1.414，而不是2。

# n 是本层输入节点数；本实验每层同宽，所以 n=node_num
w = np.random.randn(node_num, node_num) * np.sqrt(2.0 / node_num)
z = np.dot(x, w)
a = np.maximum(0, z)  # 此处使用ReLU

若n=100，三种采样分布的标准差依次为0.01、0.1和约0.1414。初始化与激活函数要配合；不要只换He权重却仍用sigmoid来声称复现这张ReLU图。

ReLU与sigmoid的反向性质不同：只要z>0，ReLU的局部导数为1，即使输出很小也是如此；z<0时导数为0（零点实现通常也取0）。因此不能把sigmoid两端饱和的解释直接套过来。小激活值会影响后续计算与参数梯度，反向又会经过权重乘法和置零门控，多层传播的整体尺度仍可能衰减。图本身只显示前向分布，没有直接测量梯度或训练准确率。
