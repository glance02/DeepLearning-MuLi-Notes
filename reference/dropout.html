Dropout层

class Dropout:
    def __init__(self, dropout_ratio=0.5):
        self.dropout_ratio = dropout_ratio
        self.mask = None

    def forward(self, x, train_flg=True):
        if train_flg:
            self.mask = np.random.rand(*x.shape) > self.dropout_ratio
            return x * self.mask
        return x * (1.0 - self.dropout_ratio)

    def backward(self, dout):
        return dout * self.mask

dropout_ratio是丢弃概率，0.2表示每个位置约有20%的概率被屏蔽，不保证每批恰好20%。np.random.rand(*x.shape)生成与输入同形的随机数组，mask为布尔数组；backward必须复用本轮前向的mask。教材层源码

训练与评价

调用本项目行为
gradient(x,t)父类调用子类loss，默认train_flg=True；产生mask后立即反向。
predict(x)默认train_flg=False；不随机屏蔽，逐个Dropout层乘保留比例。
accuracy(x,t)复用父类，经predict默认走评价模式，训练集和测试集都一样。

本项目子类在每个隐藏层的ReLU后插入Dropout，输出层不添加。顺序为Affine → ReLU → Dropout → … → Affine，反向倒序通过这些层。权重数组没有被随机删除或重新初始化。

这里的loss默认训练模式是为了配合现有父类gradient；作者扩展类则在gradient中显式传入train_flg=True。接入方式对照

采用教材的普通Dropout：训练时不除以保留比例，评价时乘保留比例。不要与inverted dropout的缩放位置混用。
