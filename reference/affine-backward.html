Affine 反向传播速查

前向 Y=XW+b。X 为 (N,D)，W 为 (D,H)，b 为 (H,)，输出 Y 与传入梯度 G 都为 (N,H)。

先读符号：式（5.15）的 X 与 ∂L/∂X 怎样理解。本书把标量损失对各输入分量的偏导数按原顺序排列成梯度。

三条公式及其元素含义

梯度矩阵公式元素形式为什么求和
dX，(N,D)G @ W.TdX[n,i] = Σⱼ G[n,j] W[i,j]同一输入影响多个输出
dW，(D,H)X.T @ GdW[i,j] = Σₙ X[n,i] G[n,j]所有样本共享权重
db，(H,)G.sum(axis=0)db[j] = Σₙ G[n,j]所有样本共享偏置

G[n,j]=∂L/∂Y[n,j]，即 dout。dX、dW、db 均是最终标量损失 L 对相应变量的梯度。

dx = np.dot(dout, self.W.T)
self.dW = np.dot(self.x.T, dout)
self.db = np.sum(dout, axis=0)
return dx

转置来自把元素级链式法则的求和排列成矩阵乘法；形状检查能辅助核对。若 L 取平均，dout 已包含相应求导因子，本层不额外除以 N。

前向保存的 self.x 用于求 dW；dW、db 保存后供参数更新使用。上述公式针对二维批输入；单样本可写成 (1,D)，因为一维 NumPy 数组的 .T 不改变形状。
