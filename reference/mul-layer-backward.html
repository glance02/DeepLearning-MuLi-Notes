MulLayer.backward 速查

标量乘法节点：out = x × y；最终标量结果为 L。

传入一份导数，返回两份导数

变量含义计算
dout∂L/∂out后续反向过程传入
dx∂L/∂xdout × self.y
dy∂L/∂ydout × self.x
dx = dout * self.y
dy = dout * self.x
return dx, dy

依据：∂out/∂x=y，∂out/∂y=x，再乘上传入的 dout（链式法则）。self.x、self.y 来自之前一次 forward 保存的输入。

“翻转”指交叉相乘，没有交换保存的值。返回的是导数；参数更新在后面的训练步骤另做。dout 不总是 1；若最终 L 就是 out，才从 ∂out/∂out=1 开始。
