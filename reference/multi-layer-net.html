网络结构

位置装的是什么例子
self.params真正要学习的权重和偏置数组W1、b1、W2、b2、W3、b3
self.layers按顺序执行计算的层对象Affine1、Relu1、Affine2、Relu2、Affine3
self.last_layer把得分与标签合成损失的对象SoftmaxWithLoss，单独保存

参数初始化与形状

all_size_list = [input_size] + hidden_size_list + [output_size]
# 例：输入4个、隐藏层[3,5]、输出2个，先各自组成列表再拼接：
# [4] + [3, 5] + [2] → [4, 3, 5, 2]

for i in range(1, len(all_size_list)):
    input_num = all_size_list[i - 1]
    output_num = all_size_list[i]
    scale = np.sqrt(2.0 / input_num)
    self.params["W" + str(i)] = scale * np.random.randn(input_num, output_num)
    self.params["b" + str(i)] = np.zeros(output_num)

+ 在这里拼接列表。每两个相邻节点数形成一层连接：4→3、3→5、5→2，分别创建 W1、W2、W3。"W" + str(i) 是字典键名，不是数学乘法。

W 的两维依次是本层输入节点数、输出节点数。b 只需要每个输出神经元一个值。He尺度每层重新按该层输入数计算；例如 W2 的尺度用3，不用最初的4。

两个隐藏层意味着三个 Affine 层，所以参数循环包含输出层。range(1,4) 产生1、2、3，不包含4。

初始化循环中的每一轮对应一个不同的层，只在构造网络时运行。训练循环反复更新已有参数，不会每次重新随机生成权重。这一点你已主动从激活值实验中识别出来。

He尺度对应教材6.2.3；当前源码的默认实现固定使用该尺度。

层对象与共享参数

self.layers["Affine" + str(i)] = Affine(
    self.params["W" + str(i)], self.params["b" + str(i)]
)
self.layers["Relu" + str(i)] = Relu()

params 只保存数组，不会自己执行矩阵乘法。Affine 对象拿着对应的 W、b，实现 x @ W + b；Relu 对象实现负值归零，并保存反向需要的 mask。

params["W1"]、params["b1"]→Affine1.W、Affine1.b→forward / backward

构造函数把数组引用直接交给 Affine，双方指向同一份参数数组。你可以在 Notebook 中观察：

test_net.layers["Affine1"].W is test_net.params["W1"]
# True

OrderedDict 按添加顺序保留计算次序。隐藏层循环每次添加 Affine 与 Relu；最后再单独添加一个 Affine 输出层。这个输出层后不接 ReLU，保留正负类别得分，随后计算损失时交给 SoftmaxWithLoss。

last_layer 单独放置，因为它的 forward 还要接收标签 t；普通 predict 只接收 x，不需要标签。

依赖实现：Affine、Relu、SoftmaxWithLoss；相关矩阵公式见Affine速查。

网络方法与返回值

方法输入返回会更新W/b吗
predict(x)x: (N,4)得分: (N,2)不会
loss(x,t)x与(N,2)的one-hot标签一个损失数值不会
accuracy(x,t)x与one-hot标签0到1的正确比例不会
gradient(x,t)同一批x、t与params同键、同形的梯度字典不会

表中使用小网络的4输入、2输出。预测返回的得分可以为负：你已经实际得到过6×2的得分数组。loss 调用损失层，其中会做 softmax 和交叉熵；accuracy 则把每行最大得分的下标作为类别编号，再与标签比较。

predict、loss 等会保存或刷新层的中间缓存；“不更新参数”不等于对象内部什么都没变。缓存用于后续反向计算。

当前标签约定：你的 accuracy 和 SoftmaxWithLoss.backward 都按 one-hot 使用标签。读取MNIST时保留 one_hot_label=True。这是当前最小版的接口，和作者通用版本的标签兼容范围不同。

按你当前三个方法与损失层backward解释；最大值下标可回顾argmax卡片。

梯度计算

self.loss(x, t)
dout = self.last_layer.backward(1)

layers = list(self.layers.values())
layers.reverse()
for layer in layers:
    dout = layer.backward(dout)

先调用 loss，是为了用当前这批 x、t 得到损失并保存匹配的缓存。Affine保存输入，Relu保存mask，损失层保存概率与标签。不能依赖很久以前、另一批样本的前向结果。

初始的1来自 ∂L/∂L=1。随后每个 backward 接收后面传来的梯度，计算对自己输入的梯度并继续传回；Affine还把对参数的梯度保存在自身的 dW、db。

SoftmaxWithLoss→Affine3→Relu2→Affine2→Relu1→Affine1
for i in range(1, self.hidden_layer_num + 2):
    grads["W" + str(i)] = self.layers["Affine" + str(i)].dW
    grads["b" + str(i)] = self.layers["Affine" + str(i)].db
return grads

第二个循环只是收集已算好的参数梯度。隐藏层有2层，range(1,2+2) 取1、2、3，把最后的输出层也收集进去。

dW = Xᵀ dout，db = 沿样本轴求和，dx = dout Wᵀ

因此 grads["W2"] 与 params["W2"] 都是(3,5)，但前者是损失对权重的梯度，后者是权重数值本身。

参数更新

# network、optimizer 在训练循环外创建
grads = network.gradient(x_batch, t_batch)
optimizer.update(network.params, grads)

# 你写的 SGD.update 内部
params[key] -= self.lr * grads[key]

SGD 用梯度决定参数该怎样改变。这里的 -= 原地修改参数数组，所以 Affine 持有的同一份 W、b 也变了。下一次 predict 就使用新参数。

固定本批x、t→loss + backward→grads→SGD更新W/b→下一批

每轮输入样本可能变化；普通训练里，输入图片本身不由优化器更新。可学习参数包括 W 与 b。

from collections import OrderedDict

import numpy as np

from common.layers import Affine, Relu, SoftmaxWithLoss


class MultiLayerNet:
    def __init__(self, input_size, hidden_size_list, output_size):
        self.input_size = input_size
        self.hidden_size_list = hidden_size_list
        self.output_size = output_size
        self.hidden_layer_num = len(hidden_size_list)

        self.params = {}

        # 吧输入层、隐藏层、输出层节点连起来
        all_size_list = [input_size] + hidden_size_list + [output_size]

        for i in range(1, len(all_size_list)):
            input_num = all_size_list[i - 1]
            output_num = all_size_list[i]

            # He初始化
            scale = np.sqrt(2.0 / input_num)

            self.params["W" + str(i)] = scale * np.random.randn(input_num, output_num)
            self.params["b" + str(i)] = np.zeros(output_num)

        # 组装隐藏层
        self.layers = OrderedDict()

        for i in range(1, self.hidden_layer_num + 1):
            self.layers["Affine" + str(i)] = Affine(
                self.params["W" + str(i)], self.params["b" + str(i)]
            )
            self.layers["Relu" + str(i)] = Relu()

        # 添加输出层
        i = self.hidden_layer_num + 1
        self.layers["Affine" + str(i)] = Affine(
            self.params["W" + str(i)], self.params["b" + str(i)]
        )

        self.last_layer = SoftmaxWithLoss()

    def predict(self, x):
        for layer in self.layers.values():
            x = layer.forward(x)

        return x

    def loss(self, x,t):
        y = self.predict(x)
        return self.last_layer.forward(y,t)

    def accuracy(self, x,t):
        y = self.predict(x)
        y = np.argmax(y,axis=1)
        t = np.argmax(t, axis=1)

        return np.mean(y == t)

    def gradient(self, x,t):
        # 前向传播
        self.loss(x,t)

        # 从损失层开始反向传播
        dout = self.last_layer.backward(1)

        layers = list(self.layers.values())
        layers.reverse()

        for layer in layers:
            dout = layer.backward(dout)

        # 手机每个Affine层的参数梯度
        grads = {}

        for i in range(1,self.hidden_layer_num +2):
            grads["W" + str(i)] = self.layers["Affine" + str(i)].dW
            grads["b" + str(i)] = self.layers["Affine" + str(i)].db

        return grads
