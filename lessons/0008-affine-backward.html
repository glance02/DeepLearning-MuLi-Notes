先读懂书中的式（5.15）：对向量求导

需要回顾向量求导记号时，先读这一段；也可以直接看式（5.13）的推导。本节沿用书中大写 X、小写分量 x₀、x₁、…、xₙ 和标量损失 L 的符号。

\[X=(x_0,x_1,\ldots,x_n)\]

这一行把多个输入分量合起来记为向量 X。最终损失依赖这些输入，可以写成 L=L(x₀,x₁,…,xₙ)；中间仍然可以经过很多层计算。

对一个分量 xᵢ 求偏导时，固定其余分量，只考察 xᵢ 的微小变化对 L 的影响。每个分量都这样求一次，再按 X 原来的顺序排列，就定义了本书使用的梯度记法：

\[\frac{\partial L}{\partial X}=\left(\frac{\partial L}{\partial x_0},\frac{\partial L}{\partial x_1},\ldots,\frac{\partial L}{\partial x_n}\right)\]

例如 X=(x₀,x₁)，L=x₀²+x₁²，则 ∂L/∂X=(2x₀,2x₁)。在 X=(3,4) 处，梯度为 (6,8)，意思是固定另一个分量时，L 对 x₀、x₁ 的局部变化率分别为6、8。

∂L/∂X 是“标量 L 对向量 X 的梯度”的整体记号，逐个分量求偏导后组成向量。本书这里把梯度写成行向量，计算时沿用这一排列。

式（5.15）先定义要收集哪些偏导数；具体怎样求每个偏导数，还要看 L 的计算规则。

当前问题：沿用书中符号推导式（5.13）

这两条公式分别计算输入梯度与权重梯度。本节沿用教材的 X、Y、W、L 符号，逐个元素求导后再写成矩阵。

\[\frac{\partial L}{\partial X}=\frac{\partial L}{\partial Y}W^{\mathsf T},\qquad \frac{\partial L}{\partial W}=X^{\mathsf T}\frac{\partial L}{\partial Y}\]

从前向 Y=XW+B 出发，先看单个样本。X 是行向量，设输入有 D 个分量，输出有 H 个分量，Wᵢⱼ 表示第 i 个输入到第 j 个输出的权重。编号从0开始：

\[y_j=\sum_{i=0}^{D-1}x_iW_{ij}+b_j\]

第一条：同一输入 xᵢ 影响所有输出 yⱼ，链式法则把各条路径的贡献相加：

\[\frac{\partial L}{\partial x_i}=\sum_{j=0}^{H-1}\frac{\partial L}{\partial y_j}\frac{\partial y_j}{\partial x_i}=\sum_{j=0}^{H-1}\frac{\partial L}{\partial y_j}W_{ij}=\left[\frac{\partial L}{\partial Y}W^{\mathsf T}\right]_i\]

乘积使用 Wᵀ，因为矩阵乘法里取其第 i 列，元素 (Wᵀ)ⱼᵢ=Wᵢⱼ，正好与上式的求和一致。

第二条：单个权重 Wᵢⱼ 只直接出现在 yⱼ 中，本地偏导是 xᵢ：

\[\frac{\partial L}{\partial W_{ij}}=\frac{\partial L}{\partial y_j}x_i=\left[X^{\mathsf T}\frac{\partial L}{\partial Y}\right]_{ij}\]

Xᵀ 把各输入排成一列，∂L/∂Y 把各输出的传入导数排成一行，二者相乘的第 i 行、第 j 列就是 xᵢ×∂L/∂yⱼ。因此结果与 W 同形。

两条式子中，∂L/∂Y 都由后续计算传回；转置后的矩阵乘法把上面的元素级链式法则一次算完。当前先理解单样本，批量版本可稍后再看。

补充：先只看一个样本

用行向量表示输入，两个输入特征、三个输出。前向为 y=xW+b。W 的第 i 行、第 j 列表示输入 xᵢ 到输出 yⱼ 的权重。

\[x=[x_1,x_2],\quad W=\begin{bmatrix}w_{11}&w_{12}&w_{13}\\w_{21}&w_{22}&w_{23}\end{bmatrix}\]
\[\begin{aligned}y_1&=x_1w_{11}+x_2w_{21}+b_1\\y_2&=x_1w_{12}+x_2w_{22}+b_2\\y_3&=x_1w_{13}+x_2w_{23}+b_3\end{aligned}\]

最终标量损失为 L。后面已经算好并传入 g=[g₁,g₂,g₃]，其中 gⱼ=∂L/∂yⱼ；这就是代码中的 dout。下面所有 d 都表示最终 L 对相应变量的导数。

链式法则与分支贡献相加：Stanford CS231n 反向传播讲义。

输入梯度：把所有输出路径加起来

x₁ 同时影响 y₁、y₂、y₃，因此这三条路径的贡献都要计入：

\[\frac{\partial L}{\partial x_1}=\sum_{j=1}^{3}\frac{\partial L}{\partial y_j}\frac{\partial y_j}{\partial x_1}=g_1w_{11}+g_2w_{12}+g_3w_{13}\]

每一项都和你学过的乘法层一样：传入导数乘以另一个乘数。对 x₂ 同理，得到 g₁w₂₁+g₂w₂₂+g₃w₂₃。

把这两个结果排成行向量，就是下面的矩阵乘法：

\[dx=[g_1,g_2,g_3]\begin{bmatrix}w_{11}&w_{21}\\w_{12}&w_{22}\\w_{13}&w_{23}\end{bmatrix}=gW^{\mathsf T}\]

W 转置后，每个输入对应的那一行权重成为一列，便于与所有输出的传入导数相乘、求和。矩阵乘法的定义直接给出了这个排列。

权重梯度：每个权重连接一对输入和输出

例如 w₁₂ 只直接出现在 y₂ 的式子中，对它求偏导得到 x₁；因此：

\[\frac{\partial L}{\partial w_{12}}=\frac{\partial L}{\partial y_2}\frac{\partial y_2}{\partial w_{12}}=g_2x_1\]

其他权重同理。一般元素为 dWᵢⱼ=xᵢgⱼ；按 W 原来的位置排列：

\[dW=\begin{bmatrix}x_1g_1&x_1g_2&x_1g_3\\x_2g_1&x_2g_2&x_2g_3\end{bmatrix}=\begin{bmatrix}x_1\\x_2\end{bmatrix}[g_1,g_2,g_3]=x^{\mathsf T}g\]

单个样本的权重梯度是一个列向量乘一个行向量，形成与 W 同形的矩阵。本节的 x 按 (1,2) 的二维行向量理解，转置后是 (2,1)；NumPy 一维数组的 .T 不会把它变成列向量。

偏置梯度与一批样本

单个样本中，bⱼ 只加到 yⱼ 上，局部导数为1，所以 dbⱼ=gⱼ。

批量时，X 为 (N,D)、W 为 (D,H)、b 为 (H,)，同一个 W 和 b 被所有 N 个样本使用。记 G=dout=∂L/∂Y：

\[Y_{nj}=\sum_{i=1}^{D}X_{ni}W_{ij}+b_j\]
\[dX_{ni}=\sum_{j=1}^{H}G_{nj}W_{ij},\qquad dW_{ij}=\sum_{n=1}^{N}X_{ni}G_{nj},\qquad db_j=\sum_{n=1}^{N}G_{nj}\]

dX 对输出编号 j 求和；共享的 dW、db 则把所有样本编号 n 的贡献相加。批量矩阵乘法正好完成这些求和：

dx = np.dot(dout, self.W.T)       # (N,H) @ (H,D) → (N,D)
self.dW = np.dot(self.x.T, dout)  # (D,N) @ (N,H) → (D,H)
self.db = np.sum(dout, axis=0)    # (N,H) 沿样本维求和 → (H,)

如果 L 是平均损失，平均因子应通过损失层的求导传到 dout 中；本层直接使用这个 dout，不另行除以 N。

教材代码把 dW、db 保存在对象中，供后续参数更新读取，并 return dx 给前一层。这里得到的是梯度，更新仍是另一个步骤。
