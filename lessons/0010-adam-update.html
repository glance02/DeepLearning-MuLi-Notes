手敲 Adam 的一次更新

将梯度、历史状态与参数更新连起来；每次只关注一个参数分量。

约5分钟公式与代码速查
这一小步的目标能把 m、v、偏差校正、参数更新逐项对应到代码，再自行手敲 Adam 类。

网络仍然先通过反向传播得到 grads。Adam 接收 params 与 grads，更新 W 和 b。下面的 g 是某一个参数的梯度，t 是更新次数；都不是输入图片或监督标签。

先保存两份历史

m 保留有正负号的梯度历史，帮助确定更新方向；v 保留梯度平方历史，参与缩放各参数分量的步长。默认 β₁=0.9、β₂=0.999。

mₜ = 0.9mₜ₋₁ + 0.1gₜ
vₜ = 0.999vₜ₋₁ + 0.001gₜ²
self.m[key] = self.beta1 * self.m[key] + (1 - self.beta1) * g
self.v[key] = self.beta2 * self.v[key] + (1 - self.beta2) * g ** 2

赋值右侧使用上一次保存的 m、v，左侧保存本次结果。与 AdaGrad 的一直累加相比，这里的旧统计量会乘保留比例；Adam 的 v 也不表示 Momentum 中的速度。

第一次更新，若 g=2、m₀=v₀=0，则 m₁=0.2，v₁=0.004。

依据Adam 原论文第2页 Algorithm 1的两条历史更新公式。

修正从零开始的影响

第一次只有一个观测，却和初始的零混合，得到的 m、v 偏小。使用已更新次数 t 做校正：

m̂ₜ = mₜ / (1−β₁ᵗ)，v̂ₜ = vₜ / (1−β₂ᵗ)
m_hat = self.m[key] / (1 - self.beta1 ** self.step)
v_hat = self.v[key] / (1 - self.beta2 ** self.step)

本例 t=1，m̂₁=0.2/(1−0.9)=2，v̂₁=0.004/(1−0.999)=4。这里的“偏差校正”不是修改网络的偏置 b；m_hat 与 v_hat 不覆盖原始历史状态。

零初始化的影响与校正见原论文第3节。

最后才更新参数

参数 ← 参数 − lr × m_hat / (√v_hat + eps)
params[key] -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

本例参数 w=1、lr=0.001，忽略很小的 eps，更新量为0.001×2/√4=0.001，得到 w≈0.999。eps 默认1e-8，用来使分母保持非零。

手敲时打开完整实现：先写初始化与同形零数组，再写这五条公式，最后接回训练循环。同一个 optimizer 在循环外创建；step 在每次 update 中加一，放在遍历参数的 for 外。
