先看形状，再看数值。

第1、3章 · 约3分钟每次只做这一件事对应手册条目
这一小步的目标能根据输入、权重与偏置的形状，预测一层网络的输出形状。

把每个轴说清楚

输入X的每一行是一个样本，每一列是一个特征。权重W₁把D个输入分量组合成H个隐藏神经元的加权和；偏置b₁给每个隐藏神经元加一个常数。

(N × D) · (D × H) + (H,) → (N × H)

内侧的D必须一致，外侧的N和H决定结果形状。sigmoid逐元素作用，不改变形状。

换一个维度，预测结果

SHAPE EXPLORER
偏置(H,)通过广播加到每一行。N=1仍保留一个批次轴，与单样本的一维写法(D,)区分。
再区分两种乘法
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
A * B      # [[5,12], [21,32]]
np.dot(A,B)# [[19,22], [43,50]]
逐元素乘法不沿中间维度求和；矩阵乘法用一行与一列相乘再求和。
