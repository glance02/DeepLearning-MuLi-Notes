LESSON 07 / BACKPROPAGATION

乘法层怎样把导数传回去

只解释你正在写的 MulLayer.backward，不展开整张网络。

第5章 · 约3分钟自己的代码
这一小步的目标能说清 dout 从哪里来，并用保存的 x、y 算出 dx、dy。

先把普通数值和导数分开

前向计算 out = x * y，同时把输入保存在 self.x 和 self.y，供反向计算使用。设后面还有计算，最终得到一个标量结果 L；在网络训练中，L 通常就是损失。

x、y→out = x × y→后续计算→L
代码变量数学含义从哪里来／传到哪里
dout∂L/∂out由后续计算的反向过程传进来
dx∂L/∂x返回给 x 所在的前面分支
dy∂L/∂y返回给 y 所在的前面分支

dout 不是 out 的数值，也不是学习率。小幅改变 out 时，它描述最终 L 的变化有多敏感。

为什么 dx 要乘 y？

固定 y，x 每增加一点，乘积就增加这“一点”的 y 倍，所以 ∂out/∂x = y。同理，∂out/∂y = x。

从 x 影响 out，再由 out 影响 L，两段影响相乘，这就是链式法则：

∂L/∂x = (∂L/∂out) × (∂out/∂x) = dout × y
∂L/∂y = (∂L/∂out) × (∂out/∂y) = dout × x
def backward(self, dout):
    dx = dout * self.y
    dy = dout * self.x
    return dx, dy

“翻转 x 和 y”是记忆提示：求 x 的导数时乘 y，求 y 的导数时乘 x。这里没有交换或修改 self.x、self.y，也没有更新参数。

例如 x=100、y=2，后面再乘税率 1.1：L=(x×y)×1.1。后面传回 dout=1.1，于是 dx=2.2、dy=110。保持数量不变，单价小幅增加 1，含税总价会增加 2.2。
