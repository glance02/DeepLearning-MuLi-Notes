## 本章解决的问题

第4章已经建立学习流程：抽取 mini-batch → 求损失对参数的梯度 → 更新参数 → 重复。第5章把求梯度的方法换成误差反向传播法，基本的参数更新规则保持为：

$$
W\leftarrow W-\eta\frac{\partial L}{\partial W}
$$

反向传播计算梯度；真正改变参数的是训练循环里的更新语句。数值梯度保留用于梯度确认。

## 5.1—5.2：计算图与链式法则

教材：[5.1 计算图，书内121—126页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=146>)；[5.2 链式法则，书内127—130页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=152>)。

- 节点：一次局部计算，例如加法、乘法、激活函数。
- 正向传播：按依赖顺序计算数值，最终得到损失。
- 反向传播：从最终损失出发，沿相反方向传递导数。
- 各节点只需知道本地运算、前向保存的信息，以及后面传来的导数。

若局部运算为 $y=f(x)$，最终损失为 $L$，链式法则为：

$$
\frac{\partial L}{\partial x}
=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}
$$

在代码中，`dout` 表示最终损失对本层输出的导数，`dx` 表示最终损失对本层输入的导数。它们与输入、输出的普通数值不同。

如果同一个变量经过多条路径影响损失，需要把各路径的导数贡献相加。广播、共享参数和矩阵乘法中的求和，都能用这个原则理解。

反向过程从 `dout = 1` 开始，因为最终损失对自身的导数是 $\partial L/\partial L=1$；其他节点接收的导数不一定为1。

## 5.3—5.4：加法层与乘法层

教材：[5.3 反向传播，书内130—134页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=155>)；[5.4 简单层的实现，书内135—139页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=160>)。一手代码：[layer_naive.py](https://github.com/oreilly-japan/deep-learning-from-scratch/blob/master/ch05/layer_naive.py)。

| 局部运算 | 局部偏导 | 反向计算 | 前向需保存什么 |
| --- | --- | --- | --- |
| $z=x+y$ | $\partial z/\partial x=1$，$\partial z/\partial y=1$ | `dx=dout`，`dy=dout` | 本例无需缓存输入 |
| $z=xy$ | $\partial z/\partial x=y$，$\partial z/\partial y=x$ | `dx=dout*y`，`dy=dout*x` | 输入 `x`、`y` |

乘法层的“翻转 x 和 y”是说：求 x 的导数时乘 y，求 y 的导数时乘 x。没有交换或修改保存的输入值。

```python
def backward(self, dout):
    dx = dout * self.y
    dy = dout * self.x
    return dx, dy
```

### 你练习过的例子

`forward(3,4)` 后调用 `backward(2)`，结果为 `(8,6)`。固定 y=4，x 从3增加到3.1，乘积增加0.4，因为乘积对 x 的偏导数为4。若后面还有 $L=5\times out$，传回该乘法层的 `dout` 就是5。

### 苹果与橘子的层对象和顺序

```text
苹果单价、数量 → mul_apple_layer ─┐
                               ├→ 加法层 → 税率乘法层 → 支付金额
橘子单价、数量 → mul_orange_layer ┘
```

反向先经过税率层，再经过加法层，最后回到苹果和橘子两条分支。独立分支之间的计算先后可以交换。

不同乘法层保存不同输入。例如苹果层保存 `(100,2)`，税率层保存 `(200,1.1)`。把两次反向计算都写成税率层，会使用错误的缓存；第二次应调用 `mul_apple_layer.backward(dapple_price)`。

`forward`、`backward` 的定义与调用要一致。你曾同时写成 `forword`、`backword`，名称匹配时仍可运行，但现已统一为教材拼写。`tax=1.1` 表示乘以含10%税的系数；`tax=1` 表示总价保持不变。

## 5.5：激活函数层

教材：[ReLU，书内139—141页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=164>)；[Sigmoid，书内141—144页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=166>)。一手代码：[common/layers.py](https://github.com/oreilly-japan/deep-learning-from-scratch/blob/master/common/layers.py)。

### ReLU：保存哪里需要阻断

$$
y=\max(0,x),\qquad
\frac{\partial L}{\partial x}=
\begin{cases}
\frac{\partial L}{\partial y},&x>0\\
0,&x\leq0
\end{cases}
$$

ReLU 在0处不可导，教材实现选择该处反向传0。数组输入时逐元素处理：

```python
# forward
self.mask = (x <= 0)
out = x.copy()
out[self.mask] = 0

# backward
dout[self.mask] = 0
dx = dout
```

`mask` 是前向输入的布尔掩码；`True` 的位置表示反向时该位置传0。正向的 `copy()` 避免直接覆盖输入数组。

### Sigmoid：保存输出即可求导

$$
y=\frac{1}{1+e^{-x}},\qquad
\frac{\partial y}{\partial x}
=\frac{e^{-x}}{(1+e^{-x})^2}
=y(1-y)
$$

所以：

$$
\frac{\partial L}{\partial x}
=\frac{\partial L}{\partial y}\,y(1-y)
$$

```python
dx = dout * self.out * (1.0 - self.out)
```

前向把输出保存在 `self.out`。这说明缓存什么，取决于反向公式需要什么；乘法层保存输入，Sigmoid 层保存输出。

## 5.6.1：Affine 层与式（5.13）的推导

教材：[书内144—148页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=169>)；式（5.13）在书内146页（PDF 第171页）。保留书中的 $X,Y,W,B,L$ 符号：

$$
Y=X\cdot W+B
$$

这里的 $Y$ 是本层加权求和的输出。在最后一个 Affine 层，它是类别得分；经过 Softmax 后才得到类别概率。

### 从每个元素得到输入梯度

先看单个样本，$X=(x_0,\ldots,x_{D-1})$，有 H 个输出。令 $W_{ij}$ 为输入 $x_i$ 到输出 $y_j$ 的权重：

$$
y_j=\sum_{i=0}^{D-1}x_iW_{ij}+b_j
$$

同一个 $x_i$ 会影响多个输出，因此把所有输出路径的贡献相加：

$$
\frac{\partial L}{\partial x_i}
=\sum_{j=0}^{H-1}\frac{\partial L}{\partial y_j}
\frac{\partial y_j}{\partial x_i}
=\sum_{j=0}^{H-1}\frac{\partial L}{\partial y_j}W_{ij}
$$

矩阵乘法取一行和一列做乘积求和。将 $W$ 的第 i 行转成 $W^{\mathsf T}$ 的第 i 列，上式恰好成为：

$$
\boxed{\frac{\partial L}{\partial X}
=\frac{\partial L}{\partial Y}\cdot W^{\mathsf T}}
$$

### 从每个元素得到权重梯度

单个权重 $W_{ij}$ 只直接出现在第 j 个输出中，所以：

$$
\frac{\partial L}{\partial W_{ij}}
=\frac{\partial L}{\partial y_j}
\frac{\partial y_j}{\partial W_{ij}}
=x_i\frac{\partial L}{\partial y_j}
$$

将 X 排成一列，将输出梯度排成一行，相乘的第 i 行、第 j 列正好是上述结果：

$$
\boxed{\frac{\partial L}{\partial W}
=X^{\mathsf T}\cdot\frac{\partial L}{\partial Y}}
$$

这就是式（5.13）的两条公式。转置来自元素级链式法则所要求的排列方式；检查形状可以帮助核对排列。

**NumPy 注意**：一维数组 `(D,)` 的 `.T` 仍为 `(D,)`。上面的单样本推导用行/列向量说明排列；自己的 Affine 实现实际接收二维批输入 `(N,D)`，单样本可保留为 `(1,D)`。

## 5.6.2：批量 Affine 与偏置求和

教材：[书内148—150页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=173>)。

| 量 | 形状 | 含义 |
| --- | --- | --- |
| $X$ | `(N,D)` | N 个样本，每个 D 个特征 |
| $W$ | `(D,H)` | 共享权重 |
| $B$ | `(H,)` | 共享偏置，广播到各样本 |
| $Y$、$\partial L/\partial Y$ | `(N,H)` | 输出及其传入梯度 |

批量时，所有样本共享 W 和 B；每个参数的梯度要累计各样本的贡献：

$$
\frac{\partial L}{\partial X_{ni}}
=\sum_j\frac{\partial L}{\partial Y_{nj}}W_{ij},\qquad
\frac{\partial L}{\partial W_{ij}}
=\sum_nX_{ni}\frac{\partial L}{\partial Y_{nj}}
$$

$$
\frac{\partial L}{\partial B_j}
=\sum_n\frac{\partial L}{\partial Y_{nj}}
$$

因此自己的代码是：

```python
dx = np.dot(dout, self.W.T)       # (N,H) @ (H,D) -> (N,D)
self.dW = np.dot(self.x.T, dout)  # (D,N) @ (N,H) -> (D,H)
self.db = np.sum(dout, axis=0)    # (N,H) -> (H,)
return dx
```

教材例子中，若 `dout=[[1,2,3],[4,5,6]]`，则 `db=[5,7,9]`。前向偏置广播给每个样本，反向就把各样本的导数按列累加回来。

`dx` 返回给前一层；`dW`、`db` 存在层对象中，之后由网络收集。这里还没有更新参数。

## 5.6.3：Softmax-with-Loss 层

教材：[书内150—153页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=175>)。

沿用教材：$a$ 是进入 Softmax 的得分，$y$ 是概率，$t$ 是 one-hot 标签：

$$
y_k=\frac{e^{a_k}}{\sum_j e^{a_j}},\qquad
L=-\sum_k t_k\log y_k
$$

这两个运算组合后，单样本的反向结果为：

$$
\frac{\partial L}{\partial a_k}=y_k-t_k
$$

例如 `y=[0.3,0.2,0.5]`、`t=[0,1,0]`，传回得分端的梯度为 `[0.3,-0.8,0.5]`。它是最终损失对得分的梯度；不能把 `y-t` 当成任意单独 Softmax 运算的反向公式。

一批 N 个样本采用平均损失，因此：

```python
batch_size = self.t.shape[0]
dx = (self.y - self.t) / batch_size
```

这里除以的是样本数。这个平均因子会随导数传到前面的层，Affine 层不再另外除以 N。当前 notebook 使用 one-hot 标签，并从 `lastLayer.backward(1)` 开始，符合上述实现的使用方式。

## 5.7.1—5.7.2：把层组装成 TwoLayerNet

教材：[书内154—158页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=179>)；一手实现：[two_layer_net.py](https://github.com/oreilly-japan/deep-learning-from-scratch/blob/master/ch05/two_layer_net.py)。

```text
forward： X -> Affine1 -> Relu1 -> Affine2 -> SoftmaxWithLoss -> L
backward：X <- Affine1 <- Relu1 <- Affine2 <- SoftmaxWithLoss <- 1
```

`predict()` 走到最后一个 Affine 层，返回得分；`loss()` 在其后接 Softmax-with-Loss。仅判断类别时，可以直接对得分按行取 argmax。

`gradient()` 的步骤：

1. `self.loss(x,t)` 完成前向计算，保存本轮反向需要的缓存。
2. 从 `dout=1` 开始调用损失层的反向传播。
3. 把 `self.layers.values()` 转成列表、反转，依次调用各层的 `backward()`。
4. 收集 Affine1、Affine2 的 `dW`、`db`，返回四项梯度字典。

| 参数与梯度 | 当前训练网络的形状 |
| --- | --- |
| `W1` / `grads['W1']` | `(784,50)` |
| `b1` / `grads['b1']` | `(50,)` |
| `W2` / `grads['W2']` | `(50,10)` |
| `b2` / `grads['b2']` | `(10,)` |

`self.params` 的数组被传给 Affine 层，层对象持有同一份参数数组；训练循环中的 `-=` 原地更新这些数组，下一次前向会用到更新后的参数。

你修正过的键名：`grads['W1']` 应读取 `self.layers['Affine1'].dW`。当前层名称是 `Affine1`、`Relu1`、`Affine2`，没有名为 `Affine` 的键。改类定义后，需重新运行定义单元格并重新创建实例。

## 5.7.3：用数值梯度作梯度确认

教材：[书内158—159页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=183>)；一手代码：[gradient_check.py](https://github.com/oreilly-japan/deep-learning-from-scratch/blob/master/ch05/gradient_check.py)。

固定同一个网络参数位置、同一批输入和标签，分别计算：

```python
grad_numerical = network.numerical_gradient(x_batch, t_batch)
grad_backprop = network.gradient(x_batch, t_batch)

for key in grad_numerical:
    diff = np.average(np.abs(grad_backprop[key] - grad_numerical[key]))
    print(key + ':' + str(diff))
```

每组参数先逐元素相减，再取绝对值，最后求平均。取绝对值可以避免正负误差相互抵消。比较期间不更新参数；数值梯度内部扰动后恢复原值。

你保存的前三个 MNIST 样本上的检查结果为：

| 参数 | 平均绝对差 |
| --- | --- |
| W1 | `4.299750694956092e-10` |
| b1 | `2.7356883460860973e-09` |
| W2 | `4.773980115833779e-09` |
| b2 | `1.4008570150964017e-07` |

这些结果支持当前样本上的两种实现很接近。不要求与教材输出逐位相同：随机初始化、中心差分近似、浮点精度和 ReLU 折点都可能影响差值。

## 5.7.4：这次实际训练与20秒的来源

教材：[书内159—160页](<../../materials/深度学习入门：基于Python的理论与实现 (斋藤康毅).pdf#page=184>)；一手代码：[train_neuralnet.py](https://github.com/oreilly-japan/deep-learning-from-scratch/blob/master/ch05/train_neuralnet.py)。

自己的设置：784→50→10、ReLU 隐藏层、batch=100、学习率0.1、10000次更新，数据设置为 `normalize=True, one_hot_label=True`。

```python
grad = network.gradient(x_batch, t_batch)
for key in ('W1', 'b1', 'W2', 'b2'):
    network.params[key] -= learning_rate * grad[key]
```

参数总数为 `784*50+50+50*10+10=39760`。中心差分每个参数需要两次损失计算，求一次完整梯度约需79520次损失计算；反向传播求一次完整梯度只需一次前向和一次反向，并复用中间结果。训练循环还会在更新后额外算一次损失用于记录。

你报告这次约20秒完成；这是本次机器与运行条件下的耗时，不是固定基准。当前保存的最后一次打印为：

```text
train acc, test acc | 0.97895, 0.9704
```

即训练准确率97.895%、测试准确率97.04%，相差0.855个百分点。准确率整体上升，中间小幅波动与随机 mini-batch 更新相符。

### 为什么是17行输出

训练集60000张、batch为100，按样本量折算约600次更新为一个 epoch。这里使用有放回随机抽样，不保证每600次恰好遍历所有样本。

```python
if i % iter_per_epoch == 0:
    ...
```

i 从0开始，所以打印位置为 `0,600,...,9600`，共17次。第一行是第一次更新后的评价；最后一行是第9601次更新后的评价，不能直接说它是第10000次更新后的准确率。10000次更新按样本量折算约16.67个 epoch。
