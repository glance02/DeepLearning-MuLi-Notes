## 1.3：基本语法

对应：[draft.py](../../mycode/入门/draft.py)、[01.py](../../mycode/入门/01.py)。

| 写法 | 含义 | 容易混淆的地方 |
| --- | --- | --- |
| `3 ** 2` | 3的平方 | `^` 不是乘方 |
| `7 / 5` | 除法，结果为 `1.4` | 与 `//` 的向下取整除法区分 |
| `a[0]`、`a[-1]` | 第一个、最后一个元素 | 索引从0开始 |
| `a[1:3]` | 取索引1、2的元素 | 包含左端，不包含右端 |
| `me['height']` | 按键访问字典 | 列表主要按位置访问 |
| `if` / `else` | 条件分支 | 缩进决定语句属于哪个分支 |
| `for i in range(3)` | 依次让 `i` 为0、1、2 | 不包含3 |
| `def f(x): ...` | 封装一段可重复调用的计算 | `return` 把结果交给调用者 |

`print()` 用于显示，`return` 用于返回函数结果。Notebook 单元格通常只自动显示最后一个表达式；要对比多个计算结果，可以显式 `print`。

## 1.5：NumPy 数组

### 列表与数组

```python
import numpy as np

a = [1, 2, 3]
x = np.array(a)

a * 2       # [1, 2, 3, 1, 2, 3]：列表重复
x * 2       # array([2, 4, 6])：逐元素乘法
```

这一区别解释了后面的函数为什么先把输入转换成 `np.array`：损失函数里的 `y - t`、`(y - t) ** 2` 都需要数值数组运算。

### 形状、维数、元素类型

```python
X = np.array([[1, 2, 3], [4, 5, 6]])
X.shape     # (2, 3)：2行、3列
X.ndim      # 2：两个轴
X.size      # 6：总元素数
X.dtype     # 查看元素类型
```

`shape` 是“每个轴有多长”，`ndim` 是“有几个轴”。一维数组 `(3,)` 与二维数组 `(1, 3)` 不同。

### 广播

广播让满足形状规则的不同数组可以一起运算。可以直觉地想成把较小数组沿某个方向重复使用，不需要自己写循环。

```python
A = np.array([[1, 2], [3, 4]])
b = np.array([10, 20])
A + b       # [[11, 22], [13, 24]]：每一行都加上 b
A * 10      # [[10, 20], [30, 40]]
```

补充记法：从最右边的轴开始比较，每对长度相同或其中一个为1，才可以广播。不能把“形状不同也能算”理解成任意形状都能算。

联系神经网络：批输入 `X @ W` 为 `(N, H)`，偏置 `b` 为 `(H,)`，相加时把同一个偏置向量用到每个样本上。

### 索引和筛选

```python
X = np.array([[51, 55], [14, 19], [0, 4]])
X[0]            # [51, 55]：取一行
X[0, 1]         # 55：取一个元素
X[[0, 2]]       # 取第0、2行
X[X > 15]       # [51, 55, 19]：布尔筛选
```

`X > 15` 得到的是布尔数组；`X[X > 15]` 才是取出满足条件的值。第4章的 `x_train[batch_mask]` 则是用整数索引数组选择多行。

## 1.6：绘图

对应：[numpy_demo.py](../../mycode/入门/numpy_demo.py)。

```python
import matplotlib.pyplot as plt

x = np.arange(0, 6, 0.1)
plt.plot(x, np.sin(x), label='sin')
plt.plot(x, np.cos(x), linestyle='--', label='cos')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.show()
```

`plot` 观察函数曲线，`imshow` 显示图像。你的代码使用 PIL 的 `Image.open()` 读图片，再交给 `imshow()`。
