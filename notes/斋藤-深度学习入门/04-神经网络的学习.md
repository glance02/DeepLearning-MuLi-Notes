## 4.1：从数据中学习

教材比较了三种思路：人工写识别规则、人工提取特征后让算法学习、让神经网络连同特征表示一起学习。“端到端”描述从输入到目标输出的学习方式，不表示不需要人选择数据、网络结构和学习设置。

| 概念 | 要记住什么 | 对应代码 |
| --- | --- | --- |
| 训练数据 | 用来调整参数 | `x_train, t_train` |

## 4.2：损失函数

网络预测为 `y`，正确标签为 `t`，损失为一个标量。学习时希望损失变小。

### 4.2.1：均方误差，式（4.1）

$$
E=\frac12\sum_k(y_k-t_k)^2
$$

对应 notebook 的 `mean_squard_error(y, t)`：

```python
return 0.5 * np.sum((y - t) ** 2)
```

逐项相减、平方、求和，再乘 `0.5`。这里按教材使用“均方误差”的名称，但当前公式实际上是**平方误差和的一半**，没有除以类别数；不要因为函数名字带 `mean` 就自行多除一次。

你使用的两个例子中，正确标签都是数字2：

| 预测情况 | 正确类2的输出 | 类7的输出 | 此公式的损失 |
| --- | --- | --- | --- |
| 类2概率最高 | 0.6 | 0.1 | 0.0975 |
| 类7概率最高 | 0.1 | 0.6 | 0.5975 |

第一个预测与标签向量更接近，所以损失更小。Notebook 单元格只自动显示最后一次调用的结果，要比较两者可以显式输出。

### 4.2.2：交叉熵误差，式（4.2）

$$
E=-\sum_k t_k\log y_k
$$

这里的标签是 one-hot：正确类别为1，其余为0；`log` 是自然对数。设正确类别是 `c`，则：

$$
E=-\log y_c
$$

因为其他项都乘以0，只留下正确类别那一项。

| 正确类别的预测概率 | 理想公式的交叉熵约为 |
| --- | --- |
| 0.9 | 0.105 |
| 0.6 | 0.511 |
| 0.1 | 2.303 |

直觉：真实答案发生时，模型越“不相信它”，受到的惩罚就越大。

你的代码加上 `delta = 1e-7`，以避免 `np.log(0)`。因此数值结果对应 `-log(y_c + delta)`，与理想公式有很小差别。

“one-hot 交叉熵只显式取正确类别的概率”不意味着其他权重完全无关：正确类别的 softmax 概率分母包含所有类别的分数。

### one-hot 标签与类别编号

```python
labels = np.array([2, 0, 1, 2])
table = np.eye(3, dtype=int)
one_hot = table[labels]
# [[0, 0, 1], [1, 0, 0], [0, 1, 0], [0, 0, 1]]
```

对应你“理解独热编码的代码”单元格。`np.eye(3)` 创建单位矩阵，编号是多少，就取第几行。

MNIST 原标签 `(60000,)` 经 `np.eye(10)[t_train]` 转换后是 `(60000, 10)`。每一行仍然只表示一个样本的类别，不是多了10个样本。

### 4.2.3：mini-batch 与平均损失，式（4.3）

$$
E=-\frac1N\sum_{n=1}^{N}\sum_k t_{nk}\log y_{nk}
$$

`N` 是参与本次计算的样本数，`k` 是类别索引。先求每个样本的损失，再对样本取平均；这里除的是样本数，不是类别数。

使用全部训练数据计算开销大，于是随机抽取一小批，近似反映整体情况。

你的“随机抽取10笔数据”单元格中：

```python
batch_mask = np.random.choice(trian_size, batch_size)
x_batch = x_train[batch_mask]
t_batch = t_train[batch_mask]
```

- `trian_size` 是你代码中的变量名，表示训练样本数。
- `batch_mask` 是样本索引数组，图像和标签必须用**同一组索引**，否则会打乱对应关系。
- 当前 `batch_size=10`，所以图像批形状为 `(10, 784)`，one-hot 标签批形状为 `(10, 10)`。
- 这里 `np.random.choice` 默认有放回抽样，因此一批中可能出现重复索引；“抽10个”不保证是10个不同样本。

第3章的批推理与本节的 mini-batch 学习都把样本组成数组，但用途不同：前者加速预测，后者用小批量估计训练所需的损失与梯度。

### 4.2.4：两种标签形式的批量交叉熵

one-hot 标签可以用 `-sum(t * log(y + delta)) / N`。

类别编号标签可以直接取每行正确类别的概率：

```python
y = np.array([[0.1, 0.2, 0.7],
              [0.8, 0.1, 0.1]])
t = np.array([2, 0])
correct_probs = y[np.arange(2), t]  # [y[0, 2], y[1, 0]]，即 [0.7, 0.8]
loss = -np.mean(np.log(correct_probs + 1e-7))
```

`np.arange(N)` 给出样本行号，`t` 给出每行的正确类别列号。两组索引配对取元素，不是取出所有行列的组合。

你的 notebook 开头定义的是单样本 one-hot 版本，没有按批大小取平均。末尾导入的 [common/functions.py](../../mycode/common/functions.py) 版本支持类别编号和 one-hot，并计算样本平均损失；执行导入后，同名 `cross_entropy_error` 会指向导入的函数。

### 4.2.5：为什么不直接优化准确率

例如真实类别是2，模型给它的概率从0.3提高到0.4，但另一个类别仍然最高，预测类别就不变。准确率没有改善，交叉熵却能反映这次进步。

对固定数据集，准确率通常是分段不变、越过某个边界才跳变的指标，绝大多数位置的导数为0，难以为梯度更新提供方向。交叉熵等损失能对连续的预测变化给出反馈。

## 4.3：数值微分

### 4.3.1：导数和中心差分

导数是局部变化率，不只是输出的变化量。式（4.4）：

$$
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}h
$$

在计算机中用一个有限的小量近似，不直接取极限。你的 `numerical_diff(f, x)` 使用中心差分：

$$
f'(x)\approx\frac{f(x+h)-f(x-h)}{2h},\qquad h=10^{-4}
$$

```python
h = 1e-4
return (f(x + h) - f(x - h)) / (2 * h)
```

分母是 `2*h`，因为两个采样位置相隔 `2*h`。`h` 并非越小越好：过小会使两个函数值在有限精度中难以区分。这里的 `1e-4` 是教材示例的取值，不是所有问题的固定最优值。

### 4.3.2：函数与切线，式（4.5）

你的函数名为 `function_l`（字母 l），教材写作 `function_1`（数字1）：

$$
f(x)=0.01x^2+0.1x,\qquad f'(x)=0.02x+0.1
$$

在 `x=5` 时，函数值是 `0.75`，导数约为 `0.2`；在 `x=10` 时，导数约为 `0.3`。函数值与导数是两个不同的量。

你画切线时的代码：

```python
tangent = function_l(a) + slope * (x - a)
```

对应直线方程 `y = f(a) + f'(a)*(x-a)`：经过点 `(a, f(a))`，斜率为 `f'(a)`。

### 4.3.3：偏导数，式（4.6）

$$
f(x_0,x_1)=x_0^2+x_1^2
$$

对其中一个变量求导时，固定其他变量。在 `(3, 4)` 处：

$$
\frac{\partial f}{\partial x_0}=2x_0=6,\qquad
\frac{\partial f}{\partial x_1}=2x_1=8
$$

不是同时把两个变量都加上 `h`。那样测到的是同时沿两个坐标移动产生的变化。

## 4.4：梯度

把各个变量的偏导数按顺序放在一起：

$$
\nabla f=\left(\frac{\partial f}{\partial x_0},\frac{\partial f}{\partial x_1}\right)
$$

你的 `numerical_gradient(function_2, np.array([3.0, 4.0]))` 返回约 `[6., 8.]`。

### 数值梯度代码在做什么

对应 notebook 中 `# 梯度` 单元格：

1. `np.zeros_like(x)` 创建与参数形状相同的梯度容器。
2. 保存当前参数分量 `tmp_val`。
3. 只把这个分量改成 `tmp_val + h`，计算 `fxh1`。
4. 只把这个分量改成 `tmp_val - h`，计算 `fxh2`。
5. 用中心差分算该分量的偏导数。
6. 恢复这个分量，再处理下一个。

恢复原值是为了让每个偏导数都在**同一个参数点**上计算。

### 梯度方向：阅读时特别留意符号

- 正梯度 `∇f` 指向局部上升最快的方向。
- 负梯度 `-∇f` 指向局部下降最快的方向；这里比较的是欧氏距离下单位长度的微小移动。
- 这提供的是当前位置的局部信息，不保证直接指向全局最小值。

**教材阅读提醒：书内第101页末的脚注说明图4-9画的是负梯度，但第102页附近部分文字直接称之为“梯度”并描述下降方向。记忆时以 `∇f` 的定义和式（4.7）中的减号区分，避免把正、负梯度记反。**

例如 `f=x0²+x1²` 在 `(3,4)` 的正梯度为 `(6,8)`，指向远离原点的方向；负梯度 `(-6,-8)` 才指向原点。

## 4.4.1：梯度下降和学习率

式（4.7）按分量更新，向量写法是：

$$
x\leftarrow x-\eta\nabla f(x)
$$

对应你定义的 `gradiant_descent()`：

```python
grad = numerical_gradient(f, x)
x -= lr * grad
```

`lr` 即学习率 `η`，控制沿负梯度走多大一步，`step_num` 控制更新次数。每一步都在新位置重新计算梯度。

对 `f=x0²+x1²`，从 `(-3,4)` 出发，梯度为 `(-6,8)`。如果 `lr=0.1`，一步后：

$$
(-3,4)-0.1(-6,8)=(-2.4,3.2)
$$

距离原点更近，函数值由25变成16。

### 学习率为什么不能随意增大

对这个特定的二次函数，解析梯度是 `2*x`，所以更新等于：

$$
x_{new}=(1-2\eta)x
$$

- `η=0.1`：每步变成原来的0.8倍，逐步靠近0。
- `η=10`：每步理论上变成原来的-19倍，来回跨过原点且幅度放大。
- `η=1e-10`：每步变化极小，有限次更新后几乎还在原位置。

这是解释你 `lr=10` 实验的直觉；数值微分在非常大的数值处还会受精度影响，不需要复现某个精确的巨大输出。

**梯度方向正确不等于任意步长都会降低损失。** 另外，梯度为0也不一定是全局最小值，还可能是局部极小、极大或鞍点。

### 代码层面的两个提醒

- 数值微分需要浮点数组。`np.array([-3.0, 4])` 因为含浮点元素，会得到浮点数组；若全是整数，微小扰动就可能被截断。
- 你的函数使用 `x = init_x` 后原地更新，`x` 和调用者的数组指向同一对象。重复比较不同学习率时，应像书里一样重新创建起点；如果想保留原数组，则可使用副本。

权重、偏置是学习算法调整的参数；学习率是事先设置的超参数。

## 4.4.2：神经网络的梯度（当前阅读位置）

### 式（4.8）：换成对权重求导

前面的平方和函数对坐标求梯度；神经网络学习则把输入 `x`、标签 `t` 固定，考察损失 `L` 随权重 `W` 怎样变化。

$$
W=\begin{pmatrix}
w_{11}&w_{12}&w_{13}\\
w_{21}&w_{22}&w_{23}
\end{pmatrix},\qquad
\frac{\partial L}{\partial W}=
\begin{pmatrix}
\frac{\partial L}{\partial w_{11}}&\frac{\partial L}{\partial w_{12}}&\frac{\partial L}{\partial w_{13}}\\
\frac{\partial L}{\partial w_{21}}&\frac{\partial L}{\partial w_{22}}&\frac{\partial L}{\partial w_{23}}
\end{pmatrix}
$$

每个元素回答“只微调这个权重，损失怎样变化”。梯度的形状与权重相同，都是 `(2,3)`。书中 `w11` 对应 Python 的 `W[0,0]`，注意下标起点。

### 已写好的 `simpleNet` 数据流

```text
x (2,) 与 W (2,3)
        ↓ np.dot(x, W)
原始分数 z (3,)
        ↓ softmax(z)
类别概率 y (3,)          正确标签 t
        └───────────────┬─────────┘
                  cross_entropy_error
                        ↓
                  标量损失 L
```

你的 `predict(x)` 返回的是原始分数；`loss(x,t)` 再计算概率和交叉熵。这个教学示例只有权重矩阵，没有偏置或隐藏层。

`self.W = np.random.randn(2, 3)` 每次随机生成初始权重，因此不同运行的分数和损失通常不同，不必与书中示例逐位相同。
