## 4.2：损失函数

网络预测为 `y`，正确标签为 `t`，损失为一个标量。学习时希望损失变小。

### 4.2.1：均方误差，式（4.1）

$$
E=\frac12\sum_k(y_k-t_k)^2
$$

对应 notebook 的 `mean_squard_error(y, t)`：

```python
return 0.5 * np.sum((y - t) ** 2)
```

逐项相减、平方、求和，再乘 `0.5`。这里按教材使用“均方误差”的名称，但当前公式实际上是**平方误差和的一半**，没有除以类别数；不要因为函数名字带 `mean` 就自行多除一次。

你使用的两个例子中，正确标签都是数字2：

| 预测情况 | 正确类2的输出 | 类7的输出 | 此公式的损失 |
| --- | --- | --- | --- |
| 类2概率最高 | 0.6 | 0.1 | 0.0975 |
| 类7概率最高 | 0.1 | 0.6 | 0.5975 |

第一个预测与标签向量更接近，所以损失更小。Notebook 单元格只自动显示最后一次调用的结果，要比较两者可以显式输出。

### 4.2.2：交叉熵误差，式（4.2）

$$
E=-\sum_k t_k\log y_k
$$

这里的标签是 one-hot：正确类别为1，其余为0；`log` 是自然对数。设正确类别是 `c`，则：

$$
E=-\log y_c
$$

因为其他项都乘以0，只留下正确类别那一项。

| 正确类别的预测概率 | 理想公式的交叉熵约为 |
| --- | --- |
| 0.9 | 0.105 |
| 0.6 | 0.511 |
| 0.1 | 2.303 |

直觉：真实答案发生时，模型越“不相信它”，受到的惩罚就越大。

你的代码加上 `delta = 1e-7`，以避免 `np.log(0)`。因此数值结果对应 `-log(y_c + delta)`，与理想公式有很小差别。

“one-hot 交叉熵只显式取正确类别的概率”不意味着其他权重完全无关：正确类别的 softmax 概率分母包含所有类别的分数。

### one-hot 标签与类别编号

```python
labels = np.array([2, 0, 1, 2])
table = np.eye(3, dtype=int)
one_hot = table[labels]
# [[0, 0, 1], [1, 0, 0], [0, 1, 0], [0, 0, 1]]
```

对应你“理解独热编码的代码”单元格。`np.eye(3)` 创建单位矩阵，编号是多少，就取第几行。

MNIST 原标签 `(60000,)` 经 `np.eye(10)[t_train]` 转换后是 `(60000, 10)`。每一行仍然只表示一个样本的类别，不是多了10个样本。

### 4.2.3：mini-batch 与平均损失，式（4.3）

$$
E=-\frac1N\sum_{n=1}^{N}\sum_k t_{nk}\log y_{nk}
$$

`N` 是参与本次计算的样本数，`k` 是类别索引。先求每个样本的损失，再对样本取平均；这里除的是样本数，不是类别数。

使用全部训练数据计算开销大，于是随机抽取一小批，近似反映整体情况。

你的“随机抽取10笔数据”单元格中：

```python
batch_mask = np.random.choice(trian_size, batch_size)
x_batch = x_train[batch_mask]
t_batch = t_train[batch_mask]
```

- `trian_size` 是你代码中的变量名，表示训练样本数。
- `batch_mask` 是样本索引数组，图像和标签必须用**同一组索引**，否则会打乱对应关系。
- 当前 `batch_size=10`，所以图像批形状为 `(10, 784)`，one-hot 标签批形状为 `(10, 10)`。
- 这里 `np.random.choice` 默认有放回抽样，因此一批中可能出现重复索引；“抽10个”不保证是10个不同样本。

第3章的批推理与本节的 mini-batch 学习都把样本组成数组，但用途不同：前者加速预测，后者用小批量估计训练所需的损失与梯度。

### 4.2.4：两种标签形式的批量交叉熵

one-hot 标签可以用 `-sum(t * log(y + delta)) / N`。

类别编号标签可以直接取每行正确类别的概率：

```python
y = np.array([[0.1, 0.2, 0.7],
              [0.8, 0.1, 0.1]])
t = np.array([2, 0])
correct_probs = y[np.arange(2), t]  # [y[0, 2], y[1, 0]]，即 [0.7, 0.8]
loss = -np.mean(np.log(correct_probs + 1e-7))
```

`np.arange(N)` 给出样本行号，`t` 给出每行的正确类别列号。两组索引配对取元素，不是取出所有行列的组合。

你的 notebook 开头定义的是单样本 one-hot 版本，没有按批大小取平均。末尾导入的 [common/functions.py](../../mycode/common/functions.py) 版本支持类别编号和 one-hot，并计算样本平均损失；执行导入后，同名 `cross_entropy_error` 会指向导入的函数。

### 4.2.5：为什么不直接优化准确率

例如真实类别是2，模型给它的概率从0.3提高到0.4，但另一个类别仍然最高，预测类别就不变。准确率没有改善，交叉熵却能反映这次进步。

对固定数据集，准确率通常是分段不变、越过某个边界才跳变的指标，绝大多数位置的导数为0，难以为梯度更新提供方向。交叉熵等损失能对连续的预测变化给出反馈。

## 4.3：数值微分

### 4.3.1：导数和中心差分

导数是局部变化率，不只是输出的变化量。式（4.4）：

$$
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}h
$$

在计算机中用一个有限的小量近似，不直接取极限。你的 `numerical_diff(f, x)` 使用中心差分：

$$
f'(x)\approx\frac{f(x+h)-f(x-h)}{2h},\qquad h=10^{-4}
$$

```python
h = 1e-4
return (f(x + h) - f(x - h)) / (2 * h)
```

分母是 `2*h`，因为两个采样位置相隔 `2*h`。`h` 并非越小越好：过小会使两个函数值在有限精度中难以区分。这里的 `1e-4` 是教材示例的取值，不是所有问题的固定最优值。

### 4.3.2：函数与切线，式（4.5）

你的函数名为 `function_l`（字母 l），教材写作 `function_1`（数字1）：

$$
f(x)=0.01x^2+0.1x,\qquad f'(x)=0.02x+0.1
$$

在 `x=5` 时，函数值是 `0.75`，导数约为 `0.2`；在 `x=10` 时，导数约为 `0.3`。函数值与导数是两个不同的量。

你画切线时的代码：

```python
tangent = function_l(a) + slope * (x - a)
```

对应直线方程 `y = f(a) + f'(a)*(x-a)`：经过点 `(a, f(a))`，斜率为 `f'(a)`。

### 4.3.3：偏导数，式（4.6）

$$
f(x_0,x_1)=x_0^2+x_1^2
$$

对其中一个变量求导时，固定其他变量。在 `(3, 4)` 处：

$$
\frac{\partial f}{\partial x_0}=2x_0=6,\qquad
\frac{\partial f}{\partial x_1}=2x_1=8
$$

不是同时把两个变量都加上 `h`。那样测到的是同时沿两个坐标移动产生的变化。

## 4.4：梯度

把各个变量的偏导数按顺序放在一起：

$$
\nabla f=\left(\frac{\partial f}{\partial x_0},\frac{\partial f}{\partial x_1}\right)
$$

你的 `numerical_gradient(function_2, np.array([3.0, 4.0]))` 返回约 `[6., 8.]`。

### 数值梯度代码在做什么

对应 notebook 中 `# 梯度` 单元格：

1. `np.zeros_like(x)` 创建与参数形状相同的梯度容器。
2. 保存当前参数分量 `tmp_val`。
3. 只把这个分量改成 `tmp_val + h`，计算 `fxh1`。
4. 只把这个分量改成 `tmp_val - h`，计算 `fxh2`。
5. 用中心差分算该分量的偏导数。
6. 恢复这个分量，再处理下一个。

恢复原值是为了让每个偏导数都在**同一个参数点**上计算。

### 梯度方向：阅读时特别留意符号

- 正梯度 `∇f` 指向局部上升最快的方向。
- 负梯度 `-∇f` 指向局部下降最快的方向；这里比较的是欧氏距离下单位长度的微小移动。
- 这提供的是当前位置的局部信息，不保证直接指向全局最小值。

**教材阅读提醒：书内第101页末的脚注说明图4-9画的是负梯度，但第102页附近部分文字直接称之为“梯度”并描述下降方向。记忆时以 `∇f` 的定义和式（4.7）中的减号区分，避免把正、负梯度记反。**

例如 `f=x0²+x1²` 在 `(3,4)` 的正梯度为 `(6,8)`，指向远离原点的方向；负梯度 `(-6,-8)` 才指向原点。

## 4.4.1：梯度下降和学习率

式（4.7）按分量更新，向量写法是：

$$
x\leftarrow x-\eta\nabla f(x)
$$

对应你定义的 `gradiant_descent()`：

```python
grad = numerical_gradient(f, x)
x -= lr * grad
```

`lr` 即学习率 `η`，控制沿负梯度走多大一步，`step_num` 控制更新次数。每一步都在新位置重新计算梯度。

对 `f=x0²+x1²`，从 `(-3,4)` 出发，梯度为 `(-6,8)`。如果 `lr=0.1`，一步后：

$$
(-3,4)-0.1(-6,8)=(-2.4,3.2)
$$

距离原点更近，函数值由25变成16。

### 学习率为什么不能随意增大

对这个特定的二次函数，解析梯度是 `2*x`，所以更新等于：

$$
x_{new}=(1-2\eta)x
$$

- `η=0.1`：每步变成原来的0.8倍，逐步靠近0。
- `η=10`：每步理论上变成原来的-19倍，来回跨过原点且幅度放大。
- `η=1e-10`：每步变化极小，有限次更新后几乎还在原位置。

这是解释你 `lr=10` 实验的直觉；数值微分在非常大的数值处还会受精度影响，不需要复现某个精确的巨大输出。

**梯度方向正确不等于任意步长都会降低损失。** 另外，梯度为0也不一定是全局最小值，还可能是局部极小、极大或鞍点。

### 代码层面的两个提醒

- 数值微分需要浮点数组。`np.array([-3.0, 4])` 因为含浮点元素，会得到浮点数组；若全是整数，微小扰动就可能被截断。
- 你的函数使用 `x = init_x` 后原地更新，`x` 和调用者的数组指向同一对象。重复比较不同学习率时，应像书里一样重新创建起点；如果想保留原数组，则可使用副本。

权重、偏置是学习算法调整的参数；学习率是事先设置的超参数。

## 4.4.2：神经网络的梯度（当前阅读位置）

### 式（4.8）：换成对权重求导

前面的平方和函数对坐标求梯度；神经网络学习则把输入 `x`、标签 `t` 固定，考察损失 `L` 随权重 `W` 怎样变化。

$$
W=\begin{pmatrix}
w_{11}&w_{12}&w_{13}\\
w_{21}&w_{22}&w_{23}
\end{pmatrix},\qquad
\frac{\partial L}{\partial W}=
\begin{pmatrix}
\frac{\partial L}{\partial w_{11}}&\frac{\partial L}{\partial w_{12}}&\frac{\partial L}{\partial w_{13}}\\
\frac{\partial L}{\partial w_{21}}&\frac{\partial L}{\partial w_{22}}&\frac{\partial L}{\partial w_{23}}
\end{pmatrix}
$$

每个元素回答“只微调这个权重，损失怎样变化”。梯度的形状与权重相同，都是 `(2,3)`。书中 `w11` 对应 Python 的 `W[0,0]`，注意下标起点。

### 已写好的 `simpleNet` 数据流

```text
x (2,) 与 W (2,3)
        ↓ np.dot(x, W)
原始分数 z (3,)
        ↓ softmax(z)
类别概率 y (3,)          正确标签 t
        └───────────────┬─────────┘
                  cross_entropy_error
                        ↓
                  标量损失 L
```

你的 `predict(x)` 返回的是原始分数；`loss(x,t)` 再计算概率和交叉熵。这个教学示例只有权重矩阵，没有偏置或隐藏层。

`self.W = np.random.randn(2, 3)` 每次随机生成初始权重，因此不同运行的分数和损失通常不同，不必与书中示例逐位相同。

### 求网络权重的梯度：函数与求导位置

当前 notebook 已写出：

```python
def f(W):
    return net.loss(x, t)

dW = numerical_gradient(f, net.W)
```

`numerical_gradient` 接收两类信息：`f` 提供函数的计算规则，`net.W` 提供要计算梯度的位置，即当前各权重的具体取值。

这与 `numerical_gradient(function_2, np.array([3.0,4.0]))` 相同：数组不代替函数，它告诉我们在函数的哪个位置求梯度。神经网络中把输入样本和标签固定，逐个扰动权重来观察损失。

### 为什么 `f(W)` 没直接使用形参 `W` 也能求梯度

| 名字 | 在这个调用中代表什么 |
| --- | --- |
| `net.loss(x,t)` 中的 `x` | 输入样本，示例形状为 `(2,)`，求权重梯度时不变 |
| 梯度函数内部的参数 `x` | 调用时传入的 `net.W`，形状为 `(2,3)` |
| `net.W`、预测方法里的 `self.W` | 网络保存的同一个权重数组 |

**共享数组的是梯度函数内部的 `x` 与 `net.W`，不是两个函数中恰好同名的 `x`。** 不同函数的局部变量可以同名，名字相同不表示指向同一对象。

你的梯度函数逐元素原地修改参数数组：

```text
内部 x[idx] = original + h
         ↓
net.W 对应元素改变
         ↓
调用 f(x)，其中 net.loss(输入样本, 标签) 读取当前 self.W
         ↓
得到这次扰动后的损失 L_plus
```

再改为 `original - h` 得到 `L_minus`，中心差分给出该权重的偏导数。形参 `W` 为满足函数调用形式而保留；实际权重通过网络对象间接读取。

### 临时扰动与真正更新

`x[idx] = original` 恢复刚改动的权重，让下一个分量的偏导数仍在同一个原始权重位置上计算。正常完成数值梯度计算后，权重恢复原样，得到与其同形的 `dW`。

真正的梯度下降更新是另一项操作：`W_new = W - lr*dW`。例如某权重的梯度为0.2、学习率为0.1，更新量为-0.02，即该权重减少0.02。求梯度本身不等于已经完成学习更新。

另外，末尾导入的 [common/gradient.py](../../mycode/common/gradient.py) 版本使用多维索引，支持矩阵参数；前面 notebook 自定义的 `range(x.size)`、`x[idx]` 版本对应一维数组。导入会覆盖当前名字，阅读时要区分实际调用的是哪个版本。

## 4.5开头：把学习步骤串起来

1. 从训练集中随机抽取一个mini-batch，图像和标签使用相同的样本索引。
2. 固定这批数据，在当前参数处计算损失对各个参数的梯度。
3. 按 `参数 -= 学习率 * 梯度` 更新参数。
4. 回到第1步，重新抽样并继续。

教材将这种使用随机抽样数据作梯度下降的方式称为SGD（随机梯度下降）。这里“随机”描述采样；参数更新的方向仍由算出的梯度决定。

### 一次梯度计算内固定batch，下一轮更新再重新抽样

把这批数据记为B，计算某个权重偏导数时比较的是：

$$
\frac{L_B(W+h)-L_B(W-h)}{2h}
$$

这里 `W±h` 简写为只给目标权重分量加减h，其他权重固定。两次计算中的B必须相同，计算其余权重分量时也仍用B。这样观察到的损失差异才对应参数扰动，而不是同时更换数据的影响。

更新参数后，下一轮重新随机抽一批数据，继续在新的参数位置求梯度。不同轮的batch可以重叠，不保证完全不同。不断使用训练集中的不同子集，是为了让优化参考整个训练集，而不是一直只看固定的一小部分。

可以用两层过程区分：

```text
外层：抽batch → 求梯度 → 更新参数 → 再抽batch……
内层求数值梯度：固定当前batch，逐个扰动权重、比较损失、恢复原值
```

## 4.5.1：用 TwoLayerNet 组织网络计算

`simpleNet` 只有一组权重；这里的2层网络包含一个隐藏层和一个输出层，对应两组权重与偏置。输入层不计入层数。

### 参数与梯度的字典

`self.params` 是实例中保存参数的字典，`grads` 是求梯度方法构造并返回的字典。两者键名对应，每项梯度与对应参数同形。

按你当前实例 `input_size=784, hidden_size=100, output_size=10`：

| 参数键 | 参数形状 | 梯度形状 | 含义 |
| --- | --- | --- | --- |
| `W1` | `(784,100)` | `(784,100)` | 输入层到隐藏层的连接权重 |
| `b1` | `(100,)` | `(100,)` | 100个隐藏神经元的偏置 |
| `W2` | `(100,10)` | `(100,10)` | 隐藏层到输出层的连接权重 |
| `b2` | `(10,)` | `(10,)` | 10个输出神经元的偏置 |

`__init__` 用小的随机数初始化权重，用0初始化偏置。第一层权重的每一列对应一个隐藏神经元，每一行对应一个输入分量。

### 方法之间的分工

| 方法 | 输入与任务 | 返回什么 |
| --- | --- | --- |
| `predict(x)` | 输入数据，执行两层前向计算 | 各样本的类别概率 |
| `loss(x,t)` | 结合预测概率与正确标签 | 平均交叉熵，一个标量 |
| `accuracy(x,t)` | 比较预测类别与真实类别 | 预测正确的比例 |
| `numerical_gradient(x,t)` | 固定这批数据，分别对四项参数求导 | 与参数键名对应的梯度字典 |

对于一批N个样本，前向传播的形状为：

```text
x (N,784)
 → x @ W1 + b1：a1 (N,100)
 → sigmoid：z1 (N,100)
 → z1 @ W2 + b2：a2 (N,10)
 → 按每个样本做softmax：y (N,10)
```

`sigmoid` 逐元素激活，不改变形状。它应由 [common/functions.py](../../mycode/common/functions.py) 导入；第3章 notebook 中的定义不会自动进入该模块。本次已补上工具文件中缺少的实现。

### accuracy：概率变成类别，再统计正确比例

`np.argmax(y, axis=1)` 对每一行取最大概率的位置，得到各样本的类别编号；例如 `[0.1,0.7,0.2]` 对应编号1，而不是返回0.7。

书中这版 `accuracy` 的标签t按二维one-hot形式传入，`np.argmax(t, axis=1)` 将其转换为真实类别编号。对比两个编号数组得到布尔数组，True按1计数：

```text
预测类别：[1,0,2,1]
真实类别：[1,2,2,0]
逐项比较：[True,False,True,False]
准确率：2 / 4 = 0.5，即50%
```

`x.shape[0]` 是样本数；分母不是类别数。`y` 在取argmax后已经从概率数组变成类别编号数组，注意同一个变量名在前后保存的内容不同。

### numerical_gradient：同一个损失，分别对四组参数求导

`loss_W = lambda W: self.loss(x,t)` 与前面的包装函数一样，固定样本和标签，通过网络对象读取当前参数。方法内依次调用公共数值梯度函数，对 `W1,b1,W2,b2` 求偏导并放入grads。

例如 `grads['W1'] = numerical_gradient(loss_W, self.params['W1'])` 返回第一层权重的梯度；其形状为 `(784,100)`。这一步测量梯度，后面的训练循环才会用它真正更新参数。

### 两个同名 numerical_gradient：方法调用工具函数

| 调用写法 | 对应实现 | 返回内容 |
| --- | --- | --- |
| `net.numerical_gradient(x,t)` | `TwoLayerNet` 的实例方法 | 四组参数梯度组成的字典 |
| `numerical_gradient(loss_W,param)` | 从 `common.gradient` 导入的工具函数 | 一个参数数组的梯度 |

方法内部直接写 `numerical_gradient(...)` 时，Python查找该方法的局部及全局名字，不会自动把它当成同名类方法。这里的全局名字由 `from common.gradient import numerical_gradient` 导入。

因此这是类方法分别调用工具函数四次，不是递归。如果在这个方法内部写 `self.numerical_gradient(x,t)`，才是再次调用当前实例的同一个方法，会形成递归。

## 4.5.2：从训练集中抽出一个mini-batch

`np.random.choice(train_size,batch_size)` 从0到 `train_size-1` 随机抽取指定数量的整数。它返回的是样本编号，不是图像本身。

```python
batch_mask = np.random.choice(train_size, batch_size)
x_batch = x_train[batch_mask]
t_batch = t_train[batch_mask]
```

两份数据使用同一组编号，才能保持图像和正确标签配对。默认允许有放回抽样，所以编号可能重复；需要在一次抽样中不重复时，可以加 `replace=False`。

当 `batch_size=100`，训练图像为 `(60000,784)`、标签为 `(60000,10)`：

| 变量 | 形状 | 含义 |
| --- | --- | --- |
| `batch_mask` | `(100,)` | 100个样本编号 |
| `x_batch` | `(100,784)` | 100张展平图像 |
| `t_batch` | `(100,10)` | 对应的100个one-hot标签 |

抽样改变样本数，特征与类别维度保持不变。`batch_size` 控制一次抽多少样本，`iters_num` 控制训练循环更新多少次。

### 求梯度、更新参数、记录损失

```python
grad = network.numerical_gradient(x_batch, t_batch)
for key in ('W1', 'b1', 'W2', 'b2'):
    network.params[key] -= learning_rate * grad[key]
```

`grad` 保存当前这批数据的损失对四项参数的梯度。求梯度过程中临时扰动参数并恢复；真正改变网络参数的是循环中的 `-=`。相同key把参数数组与其梯度数组配对，进行逐元素更新。

随后用更新后的参数，对同一个batch计算 `loss` 并存入 `train_loss_list`。换到下一轮batch时，损失计算用到的数据也变了，因此记录的损失可以波动，不要求每一步严格下降。

当前训练实例叫 `network`，隐藏层为50；前面验证形状的实例叫 `net`，隐藏层为100。比较参数形状时要区分两个实例。

### 实际运行提醒：数值梯度的计算量

当前训练网络为784→50→10，共 `784*50+50+50*10+10=39760` 个参数。每个参数的中心差分需要两次损失计算，所以一次参数更新需约79520次损失计算，10000轮接近8亿次。

2026-10-29，在本机训练所用Python环境中，按相同网络与batch形状做短时损失计算测量，外推一轮约43—54秒，10000轮约118—149小时（约5—6天）。这是依赖机器负载的估算，不是所有电脑的固定耗时，也没有读取正在运行的内核迭代计数。当前学习可先运行1轮或使用小网络理解流程；后续第5章的反向传播会用更高效的方法计算梯度。

教材中的 `# grad = network.gradient(x_batch,t_batch)` 是反向传播版本的替代调用。当前类尚未实现该方法，只取消注释会报AttributeError；实现后可替换数值梯度调用，返回字典的键名和形状与现有更新逻辑对应。

## 4.5.3：用测试数据评价泛化

训练的目标是处理未见数据，而不只是降低某个训练batch的损失。训练损失下降是一项学习信号，但仍需查看不参与参数更新的测试数据表现。

- 训练准确率：对训练数据预测正确的比例。
- 测试准确率：对测试数据预测正确的比例，用来评价泛化表现。
- 如果训练表现很好，测试表现明显较差，需要关注过拟合等原因；不能仅据训练损失下降就宣布模型已经学好。

这里不是说参数只在训练时有效：训练和推理使用同一组学到的参数，问题在于这组参数适应训练数据，却没有把规律很好地推广到未见数据。

本节按固定间隔记录两种准确率，避免每次更新都评价整个数据集。

### iteration与epoch

一次iteration在这里指抽一批数据、求梯度并更新参数一次。一个epoch通常指把训练数据完整遍历一遍。

60000个训练样本、batch为100，按样本量折算约600次更新为一个epoch。但本书代码每次随机有放回抽样，600次后不保证每个样本都被看到；书内116页的译注也特别区分了这种抽样与打乱后逐批遍历。

当前代码使用 `if i % iter_per_epoch == 0`，而i从0开始，因此第一次更新后就记录准确率；之后在i=600、1200等位置再记录。若希望满600次更新才首次记录，可改用 `(i+1) % iter_per_epoch == 0`。目前iters_num为10，不会按后者条件完成一次epoch记录。

### 已修正的记录笔误

此前代码把 `test_acc` 同时追加到了两个准确率列表。训练列表应记录训练准确率：

```python
train_acc_list.append(train_acc)
test_acc_list.append(test_acc)
```

否则两条保存的曲线会相同，不能据此判断训练、测试表现一致。2026-10-29，用户已自行改为上述写法，并已核对 notebook 源码；无需为核对这行记录逻辑重新执行漫长的数值梯度训练。
