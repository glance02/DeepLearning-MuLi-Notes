## 3.1：把神经元分成两步

式（3.4）、（3.5）：

$$
a=b+w_1x_1+w_2x_2,\qquad y=h(a)
$$

先算加权和 `a`，再通过激活函数 `h` 得到输出。感知机也能这样描述，只是它采用阶跃函数。

本书把输入层叫第0层，后面依次为隐藏层、输出层。“3层网络”按3组权重计算，不包含输入层。

## 3.2：激活函数

对应 notebook 开头的 `step_function()`、`sigmoid()`、`relu()`。

| 函数 | 数学表达 | 关键性质 | 代码 |
| --- | --- | --- | --- |
| 阶跃 | 输入大于0时为1，否则为0 | 输出只有0、1；在0处跳变 | `np.array(x > 0, dtype=int)` |
| sigmoid，式（3.6） | $h(x)=1/(1+e^{-x})$ | 平滑；输出在0到1之间；`h(0)=0.5` | `1 / (1 + np.exp(-x))` |
| ReLU，式（3.7） | $h(x)=\max(0,x)$ | 负值置0，正值保留；整体非线性 | `np.maximum(0, x)` |

sigmoid 输出在0到1之间，但隐藏层里某个 sigmoid 值不因此自动成为“某类别的概率”；还要看模型如何定义这个输出。

### 为什么隐藏层需要非线性

只做线性变换，多层可以合并成一层。例如 `h(x) = c*x`，连续三次就是 `c**3*x`。

即使加偏置，也有：

$$
(XW_1+b_1)W_2+b_2
=X(W_1W_2)+(b_1W_2+b_2)
$$

仍然是一次“矩阵乘法加偏置”。非线性激活让层数增加能够带来新的表达能力。这里说的是隐藏层；输出层可以按任务使用恒等函数。

## 3.3：矩阵运算与形状

| 运算 | 含义 | 形状要求（本章使用的情形） |
| --- | --- | --- |
| `A * B` | 逐元素相乘 | 形状相同或可广播 |
| `np.dot(A, B)` | 二维矩阵乘法 | `(m, n)` 乘 `(n, p)` 得到 `(m, p)` |
| `np.dot(x, W)` | 用一个向量计算多个输出 | `(D,)` 乘 `(D, H)` 得到 `(H,)` |

先核对“中间维度相同”，再看结果的形状。矩阵乘法一般不能交换顺序。

你在“使用 NumPy 矩阵来实现神经网络”单元格中写过：

```python
X = np.array([1, 2])
W = np.array([[1, 3, 5], [2, 4, 6]])
Y = np.dot(X, W)  # [5, 11, 17]
```

例如第一个输出是 `1*1 + 2*2 = 5`。`W` 的每一列对应一个输出神经元，列里包含从所有输入连过来的权重。

## 3.4：3层神经网络的前向传播

式（3.9）的矩阵形式：

$$
A^{(1)}=XW^{(1)}+B^{(1)},\qquad Z^{(1)}=\operatorname{sigmoid}(A^{(1)})
$$

对应你的 `A1 = np.dot(X, W1) + B1`、`Z1 = sigmoid(A1)`。

```text
输入 X (2,)
  → 乘 W1 (2,3)，加 b1 (3,) → a1 (3,) → sigmoid → z1 (3,)
  → 乘 W2 (3,2)，加 b2 (2,) → a2 (2,) → sigmoid → z2 (2,)
  → 乘 W3 (2,2)，加 b3 (2,) → a3 (2,) → 恒等函数 → y (2,)
```

权重是每条连接的参数，偏置是每个输出神经元的参数。激活函数逐元素作用，不改变这些数组的形状。

你的 notebook 用 `init_network()` 返回保存参数的字典，用 `forword(network, x)` 执行前向传播；书中函数名拼作 `forward`，这里按你实际使用的名字对应。这个小网络的输出约为 `[0.3168, 0.6963]`。

公式中的上标 `(1)` 表示第1层，不是乘方。书中单条连接的下标顺序见3.4.1；代码中的矩阵按 `X @ W` 排布，阅读时先认清输入与输出对应的轴。

## 3.5：输出层的设计

| 任务 | 本书给出的典型输出层 | 输出怎样理解 |
| --- | --- | --- |
| 回归 | 恒等函数 | 直接输出连续数值 |
| 二元分类 | sigmoid | 用一个输出表示某类的概率 |
| 单标签多类别分类 | softmax | 对各个互斥类别给出概率 |

MNIST 有0—9共10类，所以这里输出10个数。

### softmax：把分数转换成概率

式（3.10）：

$$
y_k=\frac{e^{a_k}}{\sum_i e^{a_i}}
$$

每个输出都受所有输入分数影响，因为它们共享分母。对一个样本，所有类别的输出相加等于1。

你的 `a = np.array([0.3, 2.9, 4.0])` 示例得到约 `[0.0182, 0.2452, 0.7366]`，最大概率对应类别编号2。

### 为什么减去最大值

式（3.11）说明，对一个样本的所有分数加减同一个常数，不改变 softmax 结果。令 `c = max(a)`：

$$
\frac{e^{a_k-c}}{\sum_i e^{a_i-c}}
=\frac{e^{-c}e^{a_k}}{e^{-c}\sum_i e^{a_i}}
=\frac{e^{a_k}}{\sum_i e^{a_i}}
$$

减去最大值后，最大的指数输入为0，可以避免大的正数指数造成溢出。你的 `softmax(a)` 已包含这一处理。

### 分数、概率和类别编号

```text
原始分数 a         例：[0.3, 2.9, 4.0]
softmax(a) 的概率  例：[0.0182, 0.2452, 0.7366]
argmax 的类别编号  例：2
```

softmax 不改变同一样本内的大小顺序。因此只想预测类别时，可以对原始分数直接取 `argmax`；如果需要概率或计算这里的交叉熵，则要相应的概率计算。

## 3.6：MNIST 推理

你的代码读取 `data/minist.npz`。数据集通称是 MNIST；本地文件确实拼作 `minist.npz`，路径应按实际文件名写。

| 数据 | 原始形状 | 展平后 |
| --- | --- | --- |
| 训练图像 | `(60000, 28, 28)` | `(60000, 784)` |
| 测试图像 | `(10000, 28, 28)` | `(10000, 784)` |
| 类别编号标签 | 训练 `(60000,)`，测试 `(10000,)` | 不因图像展平而改变 |

- `reshape(-1, 784)`：保留总元素数，让 NumPy 推断第一维。
- 显示一张图像时，把 `(784,)` 恢复成 `(28, 28)`。
- `get_data()` 中的 `astype(np.float32) / 255.0` 把像素从0—255缩放到0—1，与这里使用的预训练网络输入相匹配。
- 后一个 `init_network()` 读取 `sample_weight.pkl`，不是重新训练权重；同名函数在 Notebook 里会被后执行的定义覆盖。
- 准确率是 `预测正确的样本数 / 总样本数`。

### 批处理和 axis

单样本：`(784,) → (50,) → (100,) → (10,)`。

一批 `N` 个样本：`(N, 784) → (N, 50) → (N, 100) → (N, 10)`。

对 `(N, 10)` 的预测结果，每一行是一个样本，每一列是一种类别：

```python
p = np.argmax(y, axis=1)  # 每一行在类别轴上比较，得到 N 个类别编号
```

你的最后一个 `argmax` 示例输出 `[1, 2, 1, 0]`。`axis=1` 不是“对第1个样本计算”，而是沿数组的第1号轴执行操作。

### 与当前代码直接相关的提醒：批量 softmax

你在本 notebook 定义的 `softmax(a)` 使用不带 `axis` 的 `np.max` 和 `np.sum`，适合这里的一维输入；直接传入二维批数据时，会按整个数组归一化。

例如两行分数都是 `[0, 0]`，整批归一化会得到每项 `0.25`，而逐样本的概率应该每行都是 `[0.5, 0.5]`。只检查总和为1或分类准确率，可能看不出这个区别。

批处理时应检查：

```python
y.sum(axis=1)  # 每一行应约等于1
```

你已有的 [common/functions.py](../../mycode/common/functions.py) 按 `axis=-1`、`keepdims=True` 处理，支持一维和二维输入。这是代码观察，本次只记入笔记，未改 notebook。
